# 《银河帝国》复刻前期调研

调研日期：2026-09-24  
目标：确认用户截图中的游戏，收集可追溯的界面图片，为后续复刻确定参考版本。本轮没有开始游戏实现。

## 最新复刻重点：收到战报后观看舰队交火

用户进一步明确，小时候最兴奋的体验是“收到结果的时候，看那个战舰对打的小动画”，并确认双方战舰是**左右两边对射**。

这改变了原型优先级：先验证“收到战报 → 点开观看左右舰队交火 → 查看战果”的体验，再补齐经营与派遣。基地和资源系统用于让玩家对参战舰队产生投入感。

已由用户确认的内容：收到结果时观看小动画、战舰交战、左右两侧布局。尚未确认的内容：每侧舰船数量、镜头角度、开火顺序、动画长度、音效、是否可以重播，以及对应客户端版本。

本轮补充检索找到[2012 年进攻攻略中的战报说明](https://writerparty.com/party/galaxy-empire-for-iphone-attack-and-defense-strategies-part-1-attack-strategies/)，但没有找到可以核实上述动画细节的原版录像。检索还混入了《银河传说》等作品的战斗图片，不能将它们当成用户所玩版本的证据。用户的体验描述与外部资料核实结果分别记录。

首个原型的建议重点是左右舰队的可辨识轮廓、开火与命中的对应关系、击毁反馈、战果呈现。具体视觉和节奏需要继续核对；以上是设计建议，不是已经证实的原版表现。

## 1. 识别结论

用户提供的图片与 **Tap4Fun 的《银河帝国》（Galaxy Empire）早期手机版界面**高度吻合。关键对应特征包括：

- 竖屏、斜俯视工业基地，矿山、电站和仓库具有一致的建筑外观。
- 顶部厚重蓝色资源面板，左侧三类资源，右侧暗物质、能量与额外货币区域。
- 顶部军官头像与信封按钮。
- 底部 Planets / Solar System / Fleet / Store / Capsule 五个菜单。
- 建筑下方的蓝色等级铭牌，以及贴近底部的世界聊天条。

## 4. 玩法梳理

结合[游侠旧版介绍](https://m.ali213.net/android/96668.html)、[2014 年新手攻略的检索内容](https://m.ali213.net/gonglue/140805/36578.html)和玩家资料，核心循环可以概括为：

**资源生产 → 升级建筑与能源 → 研究科技 → 建造舰队 → 派遣、侦察、战斗与扩张 → 获取更多资源。**

| 系统 | 已找到的依据 | 复刻时的意义 |
| --- | --- | --- |
| 经济 | 金属、晶体、气体；能源不足会降低生产率；仓库限制储量 | 产能、供电、容量之间形成选择 |
| 基地 | 建筑有独立等级，矿山、电站、仓库、工厂等分工 | 点击建筑查看详情与升级，是主屏最常用操作 |
| 科技与造舰 | 旧版介绍明确提到研究科技和建造舰船 | 将资源积累转化为新能力 |
| 星系 | 截图包含银河、星系、星球坐标及目标信息 | 多星球导航与派遣目的地 |
| 舰队 | 选舰、填坐标、派遣以及查看飞行中舰队 | 离线时间和到达时机成为策略的一部分 |
| 社交 | 聊天、邮件、联盟 | 支撑长期多人竞争 |
| 商业化 | 暗物质、军官购买及商店等界面 | 本轮只记录，首轮原型无需全部实现 |

玩家亲历攻略 [Galaxy Empire Startup Guide（2013）](https://menssurvivalguide.wordpress.com/2013/06/03/galaxy-empire-startup-guide/) 还记录了侦察后进攻、回收残骸、利用殖民星转移舰队等做法。这可以帮助理解旧玩家的实际玩法，但它不是官方规格，不能直接当成所有版本通用的规则。

本轮没有查明原版完整公式、科技前置树、战斗结算算法或各服速度。不能直接把 OGame 的数值表当作 Galaxy Empire 的原版数据。

## 5. 外观复刻重点

以下是根据图片做出的视觉分析，不是对原游戏引擎的判断。

1. **竖屏和高密度面板**：主画面上方是固定资源栏，下方是聊天与导航，中间留给可查看的基地。
2. **斜俯视工业基地**：金属平台、道路、悬崖和裸露地表；建筑轮廓偏写实，有旧式预渲染贴图的观感。
3. **深蓝底色与青色发光边框**：配合银灰机械框架、斜切角和较强的渐变。
4. **小型建筑铭牌**：建筑名称和 Lv 等级贴近对应建筑，而非大量现代卡片。
5. **少量醒目的活动信号**：黄色感叹号、白色信封和资源图标，在偏暗画面里突出。
6. **舰船与星图沿用相同面板语言**：让经营、导航和派遣保持一致。

用户补充的核心记忆是“收到战报 → 打开左右舰队交战动画 → 查看战果”。根据其进一步要求，首版范围已扩为完整经典玩法：经营、科技、造舰、殖民、侦察、战斗回放、残骸回收和造月都应接通；不再以仅完成战报动画为首版终点。具体数值、证据限制和范围见 [数值系统与完整首版范围](./银河帝国-数值系统与完整首版范围.md)。目前完成的是调研与规格整理，游戏尚未开始实现。
