# 银河帝国：建筑、舰船、造月规则与完整首版范围

调研日期：2026-09-24  
目标游戏：Tap4Fun 的 Galaxy Empire；以用户所附早期基地截图为外观参考。  
体验重点：**收到战报后，观看左右两边舰队对射的小动画。** 这一布局来自用户记忆，尚无经核对的原版回放视频。

## 1. 本轮结论与资料边界

可以找到相当多的升级和舰船数值。当前已整理：

- **21 项建筑/设施**：包括常规经济与生产设施、月球设施，以及有版本差异的后期设施；部分仅有名称。
- **67 行已见建筑等级成本**：主要是三种矿山、电站与雷达的低等级数据，另有其他建筑的起始成本。
- **16 项科技**：首级费用、已见前置、作用；其中超高温和反重力属于需要单独核验的后期内容。
- **29 项单位**：6 类民用单位、7 类常规战舰、5 类后期舰船、9 类防御设施、2 类导弹。数量包含只有名称、参数不全的条目，不能理解为29类已全部还原。
- **残骸、造月、月球建设、虫洞传送**的主要关系及数值线索。

主要来源是玩家维护的 [Galaxy Empire Wiki](https://galaxyempire.fandom.com/wiki/Galaxy_Empire_Wiki)，并用旧攻略交叉核对造月。页面包含不同年份、平台和军官加成数据，**不是原版官方数据库，也尚未与用户截图的精确客户端版本绑定。** 所有中文名称是方便阅读的暂译，英文 ID 保留在数据文件中。

证据分为三类：

1. **已见数值**：页面确实写出了这个数字，但仍可能有笔误或版本差异。
2. **候选重建规则**：由多行数字归纳，或为实现补足精确计算方式；不能冒称原版公式。
3. **未确认**：数据文件保留 null，不以0代替，也不从 OGame 自动补齐。

常规矿山成本可以先用以下候选式描述：

```text
升至 L 级的资源成本 = floor(该资源一级成本 × 倍率^(L − 1))
```

例如金属矿升到5级是 **303金属、75晶体**，升到10级是 **2,306金属、576晶体**，与页面低等级行一致。[金属矿原表](https://galaxyempire.fandom.com/wiki/Metal_Mine)

### 工期与产量的限制

部分建筑页面提供社区拟合工期：

```text
秒数 = (1 − 折扣比例) × A × exp(B × 目标等级) / (机器人工厂等级 + 1)
```

本轮已把10项建筑页面的拟合系数保存在JSON中，但它们仍缺服务器速度、最短时间、纳米工厂叠加等条件。它们可用来比对早期实机数据，不能直接称为原版精确公式。[机器人工厂的拟合说明](https://galaxyempire.fandom.com/wiki/Robotics_Facility)

矿山每小时产量也有表，但其中混有军官和温度等加成。例如金属矿无加成/加成栏存在不一致，气体矿部分行甚至在升级后变小。本轮没有用这些行硬凑一条“原版产量公式”。后续规则中应独立保留基础产量、温度、供电比例、科技/军官加成和服务器速度。[金属矿](https://galaxyempire.fandom.com/wiki/Metal_Mine)、[气体矿](https://galaxyempire.fandom.com/wiki/Gas_Mine)

## 5. 残骸造月

用户记得的玩法有明确资料：**交战后，舰队损失形成残骸，有一定概率在交战星球旁形成月球。** 并不是在造船厂里把材料合成月球。

旧资料记载的主要数值：

- 每 **400,000** 有效残骸对应 **1%** 造月概率。
- 普通规则下最高 **20%**，也就是约 **8,000,000** 有效残骸。
- 攻守双方的损失都可能参与残骸统计。
- 满足最高档也只有20%概率，并不保证出现月球。

以上在 [Moon社区条目](https://galaxyempire.fandom.com/wiki/Moon)、[2013玩家攻略](https://menssurvivalguide.wordpress.com/2013/06/03/galaxy-empire-startup-guide/) 和 [2012造月指南](https://writerparty.com/party/galaxy-empire-for-iphone-how-to-get-a-moon-base/) 中有对应线索。道具另有提高概率的说法，具体与普通上限的关系没有确定。

可用于复刻的候选计算式：

```text
普通造月概率 = min(20%, floor(本次有效残骸 / 400000) × 1%)
```

这里将阶梯概率具体化为向下取整，是实现层面的重建；原版边界处理仍应与真实战报核对。

残骸比例有资料冲突：许多舰船表和独立攻略支持 **造价中金属+晶体的30%**，但Moon正文又写三分之一；个别炮台行还像是把气体计入了。不能把所有对象都不加区分地代入一个确定公式。[残骸场](https://galaxyempire.fandom.com/wiki/Debris_Field)、[独立玩家攻略](https://www.it.minsk.by/16581.html)

按“金属+晶体的30%”候选规则举例：一艘轻型战斗机造价3,000金属+1,000晶体，击毁产生1,200残骸；6,667艘对应8,000,400残骸，达到普通20%档。这个例子说明损失规模，不能当作已验证的所有版本造月配方。

生成月球以后：

1. **月球基地**：起初只有一个可用建筑空间；基地每级解锁3空间，本级建设占用1，净增2。[月球基地](https://galaxyempire.fandom.com/wiki/Moon_Base)
2. **EU-X雷达阵列**：用于侦测飞向目标星球的舰队，不能扫描月球；页面记有范围“等级²−1个星系”和每次50,000气体等规则，建造前置及边界细节未齐。[EU-X雷达](https://galaxyempire.fandom.com/wiki/The_EU-X_radar_array)
3. **虫洞发生器**：两端月球都有设施后可传送舰队，不能运送资源；出发端冷却1小时。[虫洞发生器](https://galaxyempire.fandom.com/wiki/Wormhole_Generator)

造月结算仍需核验：旧残骸能否累加参与本次判定、形成月球是否消耗残骸、防御维修与残骸计算的顺序、已有月球时如何处理。残骸回收与造月成功不能在实现中无依据地绑定为同一操作。

## 6. 首版范围：完整经典玩法

按用户最新要求，先前“只做战报动画小切片”的范围建议已被替换。**首个可交付版本应能从经营玩到舰队战斗、残骸回收、殖民和造月。** 战报动画仍然是体验重点。开发内部可以逐层完成，但不能把只有按钮、没有结算关系的页面算成功能完成。

| 系统 | 首版需要接通的行为 | 完成判断 |
| --- | --- | --- |
| 资源与能源 | 三资源生产、供电、仓库上限、离线结算、星球温度 | 升级矿山会影响产量；断电、满仓和温度能实际改变结果 |
| 基地建设 | 成本、工期、前置、建造队列、建筑空间、多星球独立设施 | 扣资源、计时、完成与解锁形成一致状态 |
| 研究与船厂 | 经典科技树、7类常规战舰、6类民用单位、经典防御 | 未满足前置不能建造；科技真实影响能力 |
| 星图与殖民 | 坐标、目标信息、殖民名额、殖民船、行星与月球切换 | 新殖民地独立发展，船与资源正确转移 |
| 舰队行动 | 侦察、攻击、运输、驻扎、回收、殖民、探索、返航与召回 | 到达时间、燃料、载荷、占用名额、返航结果一致 |
| 战斗和战报 | 兵种差异、快速射击、攻防科技、防御、损失、掠夺、战报邮件 | 结算影响真实舰队和资源；回放与最终统计一致 |
| 回放体验 | 收到结果提示、打开战报、左右对射、命中/爆炸、逐段揭晓和最终战果 | 可重复播放同一场战斗，结果不变；动画节奏单独调优 |
| 残骸与月球 | 残骸场、回收容量、造月判定、月球基地、雷达、虫洞 | 舰船损失可产生后续玩法，月球有实际战略作用 |
| 持久化与多人基础 | 服务端时间和结算、存档、玩家目标、邮件、基础联盟 | 刷新/离线不重发奖励，同一到达事件只处理一次；PVP不是假目标 |

补充边界：

- 星门、星石、先驱实验室、特殊舰和后期导弹系统纳入资料目录。先确认用户所玩时期是否存在，再决定是否并入同一数值版本；资料未齐的条目不伪装成已完成。
- 普通战斗算法仍缺关键细节。[旧战斗计算器页](https://galaxyempire.fandom.com/wiki/Battle_Calculator) 提到六轮及相关计算项，这只提供重建线索，不能证明已拿到原版源码。
- 按社区重建的规则应有独立版本号。经济倍率、造月概率、舰船属性和工期应数据化，后续找到实机证据时能替换。
- 原版“收到结果—打开回放”的情绪节奏需要专门打磨：后台先结算一次并保存事件，前端再播放；重播不能重新随机、改变胜负或重复发奖励。这是拟定的实现方式，不是对原版内部代码的断言。
