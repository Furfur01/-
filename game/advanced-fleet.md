# 驱逐舰之后的舰船与科技

2026-10-22 起，六种高级舰的新订单统一在恒星系巨构船坞生产。五项科技、单舰造价和战略材料保留；旧月球旗舰订单按原工期完成。巨构费用、供能和制造速度见[恒星巨构](megastructures.md)。单舰造价与新科技基础研究费用为本地平衡值。

| 舰船 | 本地生产设施 | 科技条件（同时满足） | 金属 / 晶体 / 气体 |
|---|---|---|---|
| 裂变者 | 巨构船坞1 | 先进舰船工程1、量子指挥1 | 240,000 / 180,000 / 60,000 |
| 钛能守卫者 | 巨构船坞1 | 先进舰船工程2、超构材料2 | 60,000 / 90,000 / 40,000 |
| 噬能截击者 | 巨构船坞1 | 先进舰船工程3、相位能量学2、超空间引擎7 | 260,000 / 220,000 / 100,000 |
| 深空吞噬者 | 巨构船坞1 | 先进舰船工程3、量子指挥3、超构材料2、超空间引擎7 | 2,400,000 / 1,800,000 / 600,000 |
| 收割者 | 巨构船坞1 | 先进舰船工程4、超构材料4、反物质约束1、超空间引擎8 | 900,000 / 700,000 / 300,000 |
| 湮灭之星 | 巨构船坞1 | 先进舰船工程5、反物质约束3 | 1,200,000 / 1,800,000 / 600,000 |

全部新舰至少需要超空间科技5、超空间引擎6。没有上一舰型数量要求，没有外星部件或付费货币门槛，纳米工厂不是研究/舰船前置。2026-10-21 的资源更新为上述六舰增加专用战略材料（依表顺序为谐振晶矿4、钛能晶体6、相位凝胶8、星河稀金36、零相矿16、反物质前驱晶24）；驱逐舰不增加材料要求，旧舰与已付费队列不补扣，详见[战略资源与城邦贸易](strategic-trade.md)。

2026-10-21 起，裂变者、钛能守卫者、噬能截击者、深空吞噬者和湮灭之星的基础六维采用 Galaxy Empire Wiki；收割者缺少完整原版数值，保留单机值。钛能守卫者按重装阵线护卫舰运动，不再按轻型战机运动。特殊武器、溅射、暴击与制造经济继续采用单机规则。旧版守护者与死星仍不开放普通制造。

## 恒星系生产

每系一条巨构制造队列，最多 8 批，使用本系物流或已接入星门网络的资源池，在船坞驻地行星交付。1 / 2 / 3 级速度为 1 / 2 / 4 倍，需同级恒星资源提取器供能，不叠加纳米工厂加速。已下单批次冻结单舰工期，缺电时暂停，恢复后顺延且不再扣费。

旧旗舰中心保留等级，但停止新建、升级和接单，不自动转换成巨构船坞。旧普通及旗舰队列保留原支付、数量、工期和交付星球。
