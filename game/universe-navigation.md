正式入口已迁移为一个持久 Three.js canvas、WebGL 上下文和相机，不再通过 iframe 加载星图。`galaxy/system/planet` 只控制信息面板，不决定场景生命周期。下文保留连续导航的坐标与早期 AURORA 接入记录；当前渲染实现见 `docs/three-world-migration/README.md`。

2026-10-21：固定经济星座与战略矿点由存档中的 `strategic.constellations` / `strategic.deposits` 提供，与原视觉星座连线分开。星图行星面板可查看矿藏和联系文明，外交页可直接定位矿点。

2026-10-22：国家徽章和国名作为 Three.js 平面纹理铺在领地上，随地图旋转、倾斜和缩放，不再使用悬浮按钮。十五个势力分别使用专门设计的剪影纹章，国名置于徽章下方；整幅印记固定在真实连通领地内部，避开银心。自留地不绘制文字、徽记、专属底色或边界；原殖民保护和实际玩家殖民地显示保留。势力图层开关同步控制印记，进入恒星系及战斗时隐藏。入口为 `scripts/universe/territory-labels.js`，资源为 `assets/heraldry/nations-atlas.png`。

## 坐标与相机

底层目录保留 499 个历史坐标，不删除任何存档实体。正式星图默认显示 256 个恒星系，优先保留当前浏览星系、自有殖民地和飞行任务起终点，再依次补足。必需星系超过 256 时优先完整显示它们。星图采用用户选定的 B「疏朗开臂」棒旋星系。`galaxy-layout.json` 将 499 个编号稳定映射到选图中的真实亮点，背景白点也从同一图像采样；X/Z 使用同一像素到世界坐标变换，Y 使用固定种子的薄盘高度，因此旋转、刷新和选择时不会出现贴图与天体分离。分配时尽量接近旧显示位置，并保持星系间至少 650 单位间距；底层历史目录坐标不变。白点保留不同大小和亮度，近景渐隐并接续恒星模型。疆域始终只按 X/Z 投影计算，填充、边界和区域中心位于 Y=0。行星轨道半径为 `18 + 轨道号 × 8.5`，轨道间距约为原来的 4 倍。逻辑坐标和原距离公式保留；2026-10-22 起普通跨恒星系航行时间与气体费用乘 100，同系和银心探险保持原值。舰队动画按三维起终点及服务器任务时间插值，撤回和返航沿同一空间坐标衔接。行星使用恒星系相对位置，月球使用行星附近偏移；框选殖民地时计入高度跨度。世界坐标始终保留双精度数值，上传到 GPU 前减去相机观察中心。改变观察对象不会改写天体坐标。

单击恒星或行星立即选中，并平滑居中，保持当前缩放距离。明确选择后，滚轮持续以该天体为中心；居中途中立即滚轮会完成中心对齐，再改变距离，避免把尚未居中的位置当成缩放中心。右键或 Shift 平移解除目标跟随，此后滚轮以鼠标下的天体为缩放锚点，空白处沿当前观察中心缩放。银河、恒星系与行星均支持左键拖动环绕，工具栏可切换左键平移；双指捏合缩放。双击启动可中断的靠近，新的输入可取消自动移动。

## 地貌和建筑

银河战略层采用用户提供的 `ASTRAL_疆域与导航修复版.html` 平面 Voronoi 分区规则。256 个星系作为站点，以 2790 单位间距、4050 单位排除半径布置中立支持点，限定有限边界。相邻且属于同一显示类别（颜色）的星系合并描边，内部共边隐藏，实际所有者独立保存；异势力飞地、空洞、无主区域保持独立。共享坐标的顶点统一去重，避免裂缝及重复边线。

填充与边线使用同一个 WebGL 相机；近景自动淡出。不复制参考文件的虚构五大势力、殖民地或经济数据，所有归属来自真实存档。混居星系只绘制一个中性分区，并保留各实际所有者标记。`aurora-territory.js` 生成平面分区，`aurora-strategy.js` 管理图标与文字。旧体积网格 Worker 已不再加载。公开目录每 15 秒刷新，自有殖民地即时覆盖。

星球界面沿用参考版的左侧标题、右侧档案、底部缩略图轨道栏。缩略图单击选择、双击进入轨道，浏览其他星球不切换经营殖民地。普通星球缩略图来自参考文件，五类野怪缩略图沿用用户选定的 APK 图像，场景继续使用已确认的实际模型。档案只展示可用的真实温度、方圆、能源和威胁等信息，不填入演示用重力、人口或建筑数据。背景曝光与装饰星尘降低，近景模型与巡逻舰仍保留。

首都由 `player.home` 确定，与当前经营星球及浏览对象分离。金色徽标配实际星球名，离开画面后显示边缘定位入口。左侧帝国导航提供母星定位、自有殖民地检索与框选疆域，右侧档案提供势力图层开关。Home / H 返回首都所在星系的银河视角，保持经营对象不变。银河入口恢复稳定俯视角并支持自由旋转，恒星系与星球继续使用连续相机。势力名、首都名优先显示，其他名称随缩放出现并避让，悬停显示星系坐标与实际势力名称。

生产视图由 `aurora-navigation.js` 管理。地貌生成和动画计算在 Worker 中运行；Worker 不创建 WebGL 上下文，只提交在主上下文执行的资源与绘制指令。资源上传分批进行，等待时保持低模。

四类行星及月球共用五套有界的地貌资源缓存。低模采样使用高模的地形函数；近景采用原 AURORA 地貌、建筑、电梯和造舰演出。月球改为同一渲染器内的陨石坑地貌和月球设施映射。不同天体的绘制缓存使用坐标键，非本方天体不提交建筑绘制。建筑动画状态按本方天体保存。

低模和高模在同一相机投影下实时绘制到两个共享中间目标，以预乘透明度混合完整轮廓；低模会随高模淡入而淡出。轻微虚化仅作用于过渡天体。天体按远近整体合成，避免远处高模压住近处低模。混合比例随投影大小变化，可立即反向；首次异步就绪有短暂淡入，避免一帧跳到高模。每种地貌最多保留 16 个绘制缓存及请求，轮流处理可见目标，避免同类天体饿死或反复淘汰。

导航动画时钟独立推进：岩质行星自转 0.027 rad/s，气态行星 0.045 rad/s，月球 0.012 rad/s。低模使用旋转模型矩阵，高模使用逆旋转后的相机与光照，因此地形、建筑、气辉及拾取共享朝向。自转不会改变天体中心坐标；聚焦建筑时相机可跟随其所在经度。恒星表面持续自转、翻涌，太阳风沿弯曲流线向外传播。

`aurora-celestial.js` 的恒星已替换为用户提供的 `stellar_threejs.html` 光线追踪模型：主序星、蓝巨星、红巨星和白矮星，共享原模型的程序噪声、光球、体积日冕与立体日珥。既有五组配色映射到四类模型（原金黄色组也采用主序星），主序星、蓝巨星、红巨星、白矮星半径分别为 7、10、12、1.4。模型适配到持久 WebGL 上下文，直接使用游戏相机；恒星与行星整体按远近合成，避免恒星覆盖前景行星或背景行星穿过光球。远距离继续使用星点，近距离平滑切换模型。白矮星只有弱光晕，没有日珥或持续恒星风。原文件及替换前源码保存在 `output/stellar-import/`；需要重新导入时执行 `node scripts/import-stellar.mjs` 后重建。

该文件也提供随观察方向变化的星云背景和低模表面材质。低模代理网格采用 96 × 48 采样，沿用高模地形函数与熔岩水位；无代理时采用 64 × 40 球体。金属星的熔岩河加宽，建设地基仍由原工作区约束保持稳定。外部游戏截图和模型入口集中在 `output/celestial-references`，仅作参考，运行时没有外部图片依赖。

## 数据接口与兼容

- `GET /api/star-map`：只读公开目录，返回 `version`、`galaxy`、`systems`、`planets`。不推进结算，不创建账号，不生成或写入 NPC。尚未初始化的 NPC 位置按现行规则提供公开预览。
- 星球键固定为 `1:星系:轨道`，月球为 `moon:ID`；殖民获得真实 ID 后坐标键保持不变。目录名和已有殖民地／据点名称分开保存。
- `/api/state` 的外部星系查询、新账号、新派遣及跳跃目标仅开放第 1 银河。内部旧存档和历史任务结算仍能读取其他银河。
- 浏览天体不会改变经营殖民地。选择“管理殖民地”或顶部殖民地选择器才改变经营对象。
- `game/star-map.mjs` 固定词库版本及编号映射。执行 `node scripts/export-star-names.mjs` 导出 JSON 和带 BOM 的 CSV；导出前检查全部目录名重名。

## 星球附近实时交战

`aurora-battles.js` 在同一持久 WebGL 上下文中绘制交战舰船，位置锚定真实目标星球附近，按星球半径转换服务端战斗坐标。舰体、血量、弹丸和射击事件使用权威快照；显示缩放不参与命中和伤害计算。`map-combat.js` 订阅当前恒星系或正在观察的战斗，结束后刷新战果。交战时隐藏该目标的装饰巡逻舰，避免与真实参战单位混淆。点击战斗标记或档案的现场按钮可定位，仍使用原星图相机。历史战报可选在原位置回放、暂停、倍速和拖动进度。

## B 棒旋星系素材

选定原图保存在 `opendesign/mockups/planet-construction-review/assets/galaxy-barred-b.png`。`python scripts/build-barred-galaxy.py` 仅分析原图，不修改图像，生成 499 个实际星系显示锚点与 76,872 个背景星点（其中包括细小星尘和可分辨的亮星）。原图 SHA-256、像素坐标、大小和亮度记录在 `galaxy-layout.json`。运行时使用同一 WebGL 相机绘制立体点云，不叠加另一套螺旋公式或平面贴图。重建后运行 `npm run build:world` 更新 `planet.bundle.js`。

背景白点亮度随缩放平滑变化：近景约 6%，中景逐步提高，完整银河远景约 71%，上限 72%，仍保留不同大小与亮度层次。按视口宽高比校正缩放距离，手机与桌面采用一致的视觉分级。可选恒星的星点、细圈及近景太阳共用 `auroraStarColor` / `auroraStarType` 配色；辅助圆圈只在中距离显示，近端 2500–8000 渐入、远端 38000–75000 渐出，完整银河视角只显示有颜色的星点。去除叠加的所有者圆圈与大光晕，归属仍由疆域色块和母星标识呈现。星座连线只连接实际可选恒星，按最短邻接边组成最多 8 颗的小组，每颗至多 3 条连接，世界坐标连线长度不超过 5400，并避开 X/Z 平面交叉；连线仅用于视觉导航，不是航线或势力数据。悬停或选中时突出对应组，近景自动淡出。手机缩小标记尺寸并省略没有足够屏幕间距的短线。银河中多个恒星点击范围重叠时，选择距点击点最近的恒星中心；其他近景天体继续按深度拾取。

历史距离分级和恒星配色记录保存在 `output/playwright/barred-galaxy-distance/`；固定亮度与星座连线版本在 `output/playwright/barred-galaxy-guides/`，最初 B 版本在 `output/playwright/barred-galaxy/`。相应独立脚本已清理，不作为当前发行验证。
