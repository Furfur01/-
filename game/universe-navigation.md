# 连续银河视口

正式入口使用一个持久 iframe、canvas、WebGL 上下文和相机。`galaxy/system/planet` 只控制信息面板，不决定场景生命周期。独立 ASTRAL 页面保留作参考，正式导航不再加载它。

## 坐标与相机

第 1 银河保留 499 个 ASTRAL 星系位置，16 号星系锚点固定为 `[-6750,40,9260]`。行星使用恒星系相对位置，月球使用行星附近偏移。世界坐标始终保留双精度数值，上传到 GPU 前减去相机观察中心。改变观察对象不会改写天体坐标。

单击恒星或行星立即选中，并平滑居中，保持当前缩放距离。明确选择后，滚轮持续以该天体为中心；居中途中立即滚轮会完成中心对齐，再改变距离，避免把尚未居中的位置当成缩放中心。右键或 Shift 平移解除目标跟随，此后滚轮以鼠标下的天体为缩放锚点，空白处沿当前观察中心缩放。左键拖动环绕，双指捏合缩放。双击启动可中断的靠近，新的输入可取消自动移动。

## 地貌和建筑

生产视图由 `aurora-navigation.js` 管理。地貌生成和动画计算在 Worker 中运行；Worker 不创建 WebGL 上下文，只提交在主上下文执行的资源与绘制指令。资源上传分批进行，等待时保持低模。

四类行星及月球共用五套有界的地貌资源缓存。低模采样使用高模的地形函数；近景采用原 AURORA 地貌、建筑、电梯和造舰演出。月球改为同一渲染器内的陨石坑地貌和月球设施映射。不同天体的绘制缓存使用坐标键，非本方天体不提交建筑绘制。建筑动画状态按本方天体保存。

低模和高模在同一相机投影下实时绘制到两个共享中间目标，以预乘透明度混合完整轮廓；低模会随高模淡入而淡出。轻微虚化仅作用于过渡天体。天体按远近整体合成，避免远处高模压住近处低模。混合比例随投影大小变化，可立即反向；首次异步就绪有短暂淡入，避免一帧跳到高模。每种地貌最多保留 16 个绘制缓存及请求，轮流处理可见目标，避免同类天体饿死或反复淘汰。

导航动画时钟独立推进：岩质行星自转 0.027 rad/s，气态行星 0.045 rad/s，月球 0.012 rad/s。低模使用旋转模型矩阵，高模使用逆旋转后的相机与光照，因此地形、建筑、气辉及拾取共享朝向。自转不会改变天体中心坐标；聚焦建筑时相机可跟随其所在经度。恒星表面持续自转、翻涌，太阳风沿弯曲流线向外传播。

`aurora-celestial.js` 的恒星已替换为用户提供的 `stellar_threejs.html` 光线追踪模型：主序星、蓝巨星、红巨星和白矮星，共享原模型的程序噪声、光球、体积日冕与立体日珥。既有五组配色映射到四类模型（原金黄色组也采用主序星），恒星的游戏半径与轨道尺度保持不变。模型适配到持久 WebGL 上下文，直接使用游戏相机；恒星与行星整体按远近合成，避免恒星覆盖前景行星或背景行星穿过光球。远距离继续使用星点，近距离平滑切换模型。白矮星只有弱光晕，没有日珥或持续恒星风。原文件及替换前源码保存在 `output/stellar-import/`；需要重新导入时执行 `node scripts/import-stellar.mjs` 后重建。

该文件也提供随观察方向变化的星云背景和低模表面材质。低模代理网格采用 96 × 48 采样，沿用高模地形函数与熔岩水位；无代理时采用 64 × 40 球体。金属星的熔岩河加宽，建设地基仍由原工作区约束保持稳定。外部游戏截图和模型入口集中在 `output/celestial-references`，仅作参考，运行时没有外部图片依赖。

## 数据接口与兼容

- `GET /api/star-map`：只读公开目录，返回 `version`、`galaxy`、`systems`、`planets`。不推进结算，不创建账号，不生成或写入 NPC。尚未初始化的 NPC 位置按现行规则提供公开预览。
- 星球键固定为 `1:星系:轨道`，月球为 `moon:ID`；殖民获得真实 ID 后坐标键保持不变。目录名和已有殖民地／据点名称分开保存。
- `/api/state` 的外部星系查询、新账号、新派遣及跳跃目标仅开放第 1 银河。内部旧存档和历史任务结算仍能读取其他银河。
- 浏览天体不会改变经营殖民地。选择“管理殖民地”或顶部殖民地选择器才改变经营对象。
- `game/star-map.mjs` 固定词库版本及编号映射。执行 `node scripts/export-star-names.mjs` 导出 JSON 和带 BOM 的 CSV；导出前检查全部目录名重名。

## 构建和验证

```powershell
npm run build:command
npm test
node scripts/export-star-names.mjs
node scripts/verify-universe.mjs
```

浏览器验证自动生成独立验收存档、使用临时端口，覆盖五种天体、非本方无建筑、滚轮反转与悬停、30 次完整往返、唯一上下文、缓存稳定、桌面／移动尺寸和真实建设／取消操作。截图、视频和帧时间记录写入 `output/playwright/universe-seamless/`。使用项目现有的本地 Playwright/Chrome 环境；正式存档不会用于该验证。
