# 死星：月球改造与防守地形

状态：2026-10-15 确认的后续玩法设定，**仅记录，暂不实现**。当前死星建造、部署和战斗规则尚未按本文修改。

- 制造一颗死星必须消耗一颗月球：将该月球改造成死星，不能同时保留原月球并获得死星。
- 死星属于可部署的战略地形，类似移动的武装天体，而非普通舰队中的战舰。
- 改造完成后，可部署在玩家希望防守的星球附近。
- 该星球受到攻击时，死星作为防守地形参与防守。

改造时间、资源消耗、原月球建筑与驻军的处理、部署方式及移动时间、可部署数量、被摧毁后的状态留待后续设计，不在本次实现中假定。正式实现时需要同时处理所有权、改造占用和防止月球重复消费。

现有编队测试中的死星保留为隔离试验单位，不代表月球改造机制已经上线。
