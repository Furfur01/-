# 恒星武库

从 **巨构 → 恒星武库** 建设设施、生产燃料、装配导弹和充能。选中敌方行星后可用 **战略打击** 进入同一面板；确认目标、消耗、抵达时间和永久毁伤后发射。命中后，在武库记录或战报中点 **回看**。回放支持暂停、拖动时间和跳过，不参与服务器结算。

回放保留完整的蓄能、跨星系推进和毁伤阶段。激光、导弹、电子束分别在演出第14、15、16秒发射，跨星系打击在第26、32、29秒命中；近距离导弹缩短飞行镜头，而不是为填满时长刹车。这些是镜头时间，不改变实际战略飞行时间。导弹从舰尾开始持续加速，出膛时不重新归零速度；电子束穿出行星后继续向深空延伸，尾迹渐退。目标地表在前摇阶段预载，进入命中镜头时保留完整地貌。

电子加速器通过切线三通分流舱连接循环主环与发射支路：发射束沿切线直出，循环支路继续沿主环弯走。共用舱体在两路分离后接入加长炮口，四级超导磁镜组独立收束束流；闭合磁感线与沿线光点随蓄能增强。发射束、炮口辉光和近景镜头使用同一个实际出口坐标。

导弹命中保留小落点闪光，随后依次扩张三层完整电离球壳，抛射橙红、青蓝、紫色与浅金粒子及高温地壳碎块。镜头随冲击范围拉远；行星地表网格始终保留，最终留下完整轮廓的焦黑开裂行星。

三件武器仅向玩家开放，覆盖第 1 银河全部 499 个恒星系，不占普通派遣名额，不要求交战区。电脑母星可以打击，个人账号母星、本方及盟友行星受保护。发射后不可撤销，不经过普通命中、护盾、装甲、反导或收割者反物质免疫判定。不增加胜利结算、臣服或称帝机制。

## 装配、校准、战备

| 工程 | 金属 / 晶体 / 气体 | 白矮星物质 / 磁星物质 | 主体工期 | 供能条件 |
|---|---|---|---|---|
| 反物质合成设施 | 3亿 / 5亿 / 3亿 | 500 / 100 | 24小时 | 四级及以上戴森球 |
| 戴森棱镜阵列 | 15亿 / 25亿 / 10亿 | 2000 / 400 | 72小时 | 五级戴森球 |
| 相对论导弹发射舰 | 25亿 / 15亿 / 15亿 | 3000 / 600 | 72小时 | 五级戴森球及同系三级巨构船坞 |
| 恒星电子加速器 | 20亿 / 30亿 / 15亿 | 2500 / 800 | 96小时 | 五级戴森球 |

沿用同系巨构施工队列，每系每类一座。星图按实际进度显示结构装配、能源接入、主体完工；主体完工后再进行12小时带载校准，不消耗真实试验行星。可以在多个星系建设武库。发射舰是驻泊巨构平台，不编入普通舰队。

- **激光充能4小时、电子束6小时**，各保存一次。同系共用一条顺序充能通道，不倒扣普通工业电力。
- **反物质燃料**：每批24小时，投入1000万金属、3000万晶体、5000万气体和24单位反物质前驱晶，产出24单位燃料。
- **导弹装配**：每枚6小时，投入5000万金属、3000万晶体、1000万气体和12单位燃料。发射消耗一枚。
- 燃料与导弹存放于所属恒星系；前驱晶仍为原文明战略资源，湮灭之星配方不变。合成与装配各有一条生产线，手动开始每批生产。
- 建设、校准、制造和充能支持离线结算，不受机器人、纳米工厂加速，不提供一键完成入口。失去有效驻地或对应戴森球供能时，校准、生产及充能保留剩余时间并暂停，恢复后继续。
- 未完成的主体工程及生产批次可取消并退回原订单投入；取消须匹配当前订单编号。已经完成的校准、充能和已发射攻击不退料。

按星图距离归一化，激光与电子束飞行5—15分钟，导弹10—30分钟，无距离伤害衰减。飞行中的攻击不依赖出发地继续供能。

## 永久毁伤与后续任务

命中清除目标及关联月球的建筑、资源、生产队列、防御与在场舰船。保留天体ID、坐标、历史战报和永久毁伤类型：玻璃化、碎裂、辐照。禁止殖民、生产、重建、驻扎及野怪日刷新；不会生成替代的空白宜居星球。

已经离开的舰队继续飞行；后续到达死寂目标的任务携船和未交付货物返航。原基地已毁或失去控制时，改道至星图距离最近的同账号有效基地；没有基地则结束任务并报告舰船与货物损失。在场战斗直接终止，不能再从旧战斗检查点结算出幸存者。

同系恒星巨构保留。有其他本方行星时改挂驻地及已付款造舰/工程订单；没有驻地则停产。电脑行政中心迁往剩余殖民地；全部基地丧失后停止生产与行动，保留文明身份与历史。受击不转让整个星系领土，不清空同一物流网络其他星球库存。

## 运行代码与存档

- `arsenal-rules.mjs`：五项科技、设施费用、工期、配方与毁伤名称的共同定义。
- `arsenal.mjs`：权限、扣料、订单、战略充能、飞行时间、命中及状态投影；`desolation.mjs`：永久毁伤、战斗终止、任务返航与驻地迁移。
- 存档按需增加 `world.arsenal.strikes`、`megastructures.systems[key].arsenal`、设施 `calibration` 和行星 `devastation`；旧存档不获赠武器、科技或材料，已付款订单按原合同继续。
- `/api/state` 提供本方库存、队列、合法目标及相关打击记录；`/api/star-map` 提供公开毁伤状态和打击轨迹信息；`/api/action` 的 `arsenal` 操作使用现有账号鉴权和持久化流程。发射 `requestId` 防止重试重复扣费、重复创建攻击。
- `scripts/universe/arsenal-*.js` 复用游戏唯一 Three.js 场景、渲染器和星图坐标。原版用于棱镜、加速环、小导弹模型与命中碎片；（3）版用于发射舰，装填位置修正到轨道舰尾。原始HTML及其独立渲染器不进入游戏运行或发行包。
- 开发检查只运行 `npm test`。实际操作使用临时存档、独立会话和8390预览端口；不得连接正式8289服务测试。
