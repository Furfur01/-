# 真实战场与独立靶场

## 使用

正式主界面的战场列表、任务入口和星球档案直接定位到星图中的目标星球。舰船在星球附近实时交战，沿用当前星图的相机与 WebGL 上下文；拖动旋转、滚轮缩放。无需等战报，也不会打开额外战斗空间。

星球档案展示交战进度、最近战果、损失、掠夺量及剩余资源。胜利后按幸存舰船货舱容量装载，最多取目标各项资源的一半；舰队自动返航，抵达出发星球后自动入库，无需手动领取。新战报记录每支返航舰队的交付状态。战胜该 NPC 后可以看到当前库存；仅侦察过则明确显示带时间的侦察情报。此信息仅随个人状态返回，不进入公开星图目录。

历史战报在原位置提供可选回放，支持暂停、倍速和拖动进度，不重新计算或发放资源。舰船档案的驾驶靶场继续独立练习，不提交真实驾驶指令。

独立战场控制器保留兼容入口与回归测试：可接管自己的存活战斗舰，右键转向、W/S 油门、Space 主武器、R 导弹、T 换目标、X 对准目标、V 切换座舱/追踪、G 交还 AI。当前星图现场默认观战，未移植这些驾驶控件。以下精细驾驶画面说明适用于独立控制器。

## 战场画面

小规模交战优先保留靶场表现：总入场单位不超过 128 艘时，近中景优先使用原始完整材质、舰体、炮塔和推进器；远景切换原舰体生成的低模，每艘存活舰船始终独立显示，编队标签只用于选择。观战与驾驶直接调用靶场共用的 `drawCombatEffects` / `drawExhaust`，保留体积光束、实体弹丸、导弹尾迹及粒子；贴舰护盾命中使用真实剩余电量。当前试玩目标为双方各 50 艘，可用 `node scripts/launch-battle-trial.mjs --small` 启动隔离存档。更大舰队仍全量模拟，并沿用分级显示；所有规模统一调用靶场武器表现。高级测试舰型也生成低模，远景舰体保留最小可见尺寸。导弹按测量发射口逐枚出舱、点火转弯，每枚拥有独立碰撞与分摊伤害，待发齐射随存档保存。


默认「交火视角」从己方主力舰后侧观察并缓慢追随其交战方向，拖动镜头后转为自由观察；「舰队全景」按存活舰队范围取景。选择编队可靠近查看，驾驶和跟随仍对应同一艘真实舰船。

原始精细舰体按屏幕占比、三角形预算和实际帧时实例化显示，敌我使用同一细节规则；近处补齐原始炮塔。最远的小型舰保留编队代表与真实数量。尾焰来自原始喷口；光束亮芯、弹丸尾迹、护盾命中环与爆炸来自服务端事件或飞行弹丸，表现层不生成伤害。尾焰和短时命中特效单独限制绘制预算，避免密集交战拖慢驾驶。

源文件为 `scripts/hangar-source/battle-presentation.js` 与 `live-battle-adapter.js`。靶场不安装这些战场模块，保持原有显示与练习模拟。

## 实现边界

- 星际航行的舰队模型是不可操作的任务表示。战斗中每艘舰船独立模拟；远景每个编队显示少量真实成员及存活数量，中近景展开。显示选择不参与命中或结算。
- `spatial-profiles.mjs` 是本项目的空间玩法参数表：射程、转向、冷却等不是 APK 恢复数据。每批入场固定科技与参数，只开放正式目录中的九种战斗舰驾驶。
- `spatial-battle.mjs` 以 50ms 步长模拟；空间索引与错峰索敌限制单舰查询量。双方全灭或一方全灭结束，十分钟仍双方存活则平局。增援不延长时限，交战舰不能撤退。
- `engine.mjs` 管理任务占用、同方增援、第三方排队和唯一结算。建成、部署、返航及跳跃抵达的防守单位加入已有战斗；战略导弹仍可摧毁被战斗占用的防御，并保持不可修复规则。
- `battlefield.html` 独立加载战场控制器。`flight-runtime.js`、`ship-renderer.js` 与模型数据由靶场和战场共用；`hangar.js` 保留为同一构建内容的兼容输出。修改 `scripts/hangar-source/` 和构建脚本，再运行 `npm run build:command`，不要直接编辑生成文件。
- 完整检查点保存在存档旁的 `.battles/` 目录，世界存档使用引用；两者需要一起备份。先写不可变检查点，再原子替换世界存档。旧存档迁移只补充空战斗集合。关闭浏览器仍继续模拟，服务重启按事件时间顺序补算。

## 接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/state` | 当前玩家可见的战斗摘要及任务关联；不包含完整轨迹 |
| `GET /api/battles/:id` | 权威快照、逐舰状态及静态元数据 |
| `GET /api/battles/:id/events` | SSE；200ms 推送状态与新增事件，增援时刷新元数据，结束发送 finished |
| `POST /api/battles/:id/control` | 同源 claim / input / release；输入只含操控意图 |
| `GET /api/replay/:id` | 新战报返回 version 4 空间记录；旧战报使用原数据 |

驾驶校验所有权、存活状态、正式舰型、输入范围和递增序号。一名玩家跨战场只能控制一艘舰船，两秒无有效输入后恢复 AI。舰船的护盾、舰体、位置和冷却不随控制切换重置。

## 验证

`npm test` 运行经营、派遣、模型、战斗、回放与存档测试，包括 20,000 艘真实任务结算。新增测试还覆盖远景展开数量守恒、离线事件顺序、增援科技冻结、十分钟平局、辅助导弹、返航增援及战略导弹不可修复。

`node tests/battlefield-flow-selfcheck.mjs` 使用独立存档、临时端口验证九种正式舰型接管、只读回放和最终损失一致。`node tests/spatial-ui-selfcheck.mjs` 在 1920×1080 Chrome 下记录 1,000 / 3,000 艘混编战斗的观战、驾驶帧率、V8 内存和模拟耗时，并检查靶场仍独立运行。浏览器脚本使用当前电脑已有的 Playwright 运行时。

证据分别位于 `output/playwright/battlefield-flow/` 和 `output/playwright/native-battle/`。性能使用每种视角 30 秒采样，记录平均帧率、最慢一秒帧率、p95 帧时及显卡信息。驾驶采样使用守护者，双方护盾与舰体科技为 10，以免采样中舰船被击毁导致视角变为观战。结果仅代表当前电脑的无头 Chrome 测试，不是其他显卡或任意舰队规模的性能保证。

2026-10-15：双方阵列错开高度，接敌高度在各自编队通道内向目标靠拢。自动与手动俯仰均修改权威位置和朝向，模型、炮口、推进器使用同一姿态。新增「全武器混编」测试配比。

战场会话与主界面统一：状态、战斗快照、驾驶指令、回放和实时流均携带本地客户端标记。实时更新使用支持请求头的 fetch 事件流，保留断线重连和 finished 事件；退出时取消流和重连计时器。缺少有效身份的战场请求返回 401，不创建玩家。连接失败单独显示“暂时无法进入战场”并提供返回入口，不再误报为图形加速失败。`tests/battlefield-flow-selfcheck.mjs` 在移除所有 Cookie 的条件下检查实时流、所有正式舰型接管/释放、回放及账号数量稳定。


## 星图内交战与曲速航行（2026-10-15）

星图使用 `scripts/three-flight/map-renderer.js` 复用正式战场的 `createFlightController`、`createGalaxyRender`、事件表现和 GPU 后端。舰体、炮口、关节、尾焰、导弹轨迹、护盾命中、爆炸与反物质冲击共用原实现。星图只提供相机、缩放和星球旁的位置，不生成伤害或替代战斗模拟。透明舰队画布与星图相机同步，以天体深度代理遮挡背后的舰船；各场战斗的状态和实例批次分别保存。

点击派遣前完成共用舰船资源预加载，出发后镜头移到太空电梯的轨道船坞，舰队逐艘离港。航行前后各最多 8 秒显示舰队及曲速过渡，中段显示带数量的航行图标；短航程按比例缩短过渡，不延迟抵达。攻击抵达编队使用服务端相同的初始阵位，随后交给真实战斗快照。返航和召回沿对应航线播放，召回任务记录转向时刻。航行近景用最多约 96 个模型代表任务编队，标签仍显示真实数量；战斗沿用正式战场的逐舰身份及 LOD。

出发时默认跟随该任务：曲速中段使用独立的局部观察相机显示真实舰船模型、尾焰和舰旁光流，沿途恒星、行星和星云保留在背景中，以复用纹理的单次后处理加入轻微边缘拉伸、波动与色散，透明光流位于舰队画布下方；退出跟随后，外部星图仍以航行图标表示位置。曲速近景按画幅和舰队尺寸取景，桌面约 18 个、窄屏约 9 个代表模型，界面显示真实舰队数量、目标坐标、航程进度和服务端抵达倒计时。抵达时靠近目的地，交战时聚焦战场，返程沿用同一流程。跟随期间拖动和缩放不会退出视角，按 Esc 返回星图。所有有权限查看的战斗保留星图标记，当前星系的实时战斗无需打开独立页面即可显示。

死星和守护者暂时退出可建造、可派遣和演练选择名单；三维舰队选择也隐藏这两种舰型。原定义、模型、历史战报及已有存档数据保留，已经在途的旧任务仍能结算。

修改后运行 `node scripts/build-colony-review.mjs` 构建星图与共享舰队模块，运行 `npm run build:three` 更新独立战场。`node tests/map-combat-browser.mjs` 使用临时存档检查真实派遣、可见 GPU 像素、出入曲速、返航、自动镜头及手动观察、原地回放和移动端。截图及结果在 `output/playwright/map-combat/`；阶段跳转使用测试快照，不改正式存档或服务端计时。

`node tests/fleet-follow-browser.mjs` 检查去程、返程、窄屏单舰与混合舰队的曲速画面，包括合成后的舰体像素、真实风景像素、透明光流层级、主场景及舰队 WebGL 状态、航程信息、Esc 清除曲速效果及星图标记重新进入。截图和结果在 `output/playwright/fleet-follow/`。

实时流提前订阅所有有权查看的战斗，抵达后自动出现交战控制栏。目标星球位于镜头背面时仍渲染眼前舰队。近距离跟随以舰体尺寸确定镜头距离，缩放不再受行星半径限制；舰桥视角随舰首朝向移动，战列舰可见前甲板。从舰船列表选择或双击己方存活舰即可直接接管；摄像头下拉框与 V 键独立切换驾驶舱和第三人称。W/S 油门；战机 A/D 滚转、Q/E 或上下方向键俯仰、右键瞄准；大型舰 A/D 转向；空格主武器、R 导弹、Shift 加速、G 交还 AI，Esc 退出舰船视角。输入走原权威驾驶接口；离开星图、隐藏页面、舰船阵亡、战斗结束或更换战斗时释放控制。回放只观察，不允许接管。

`node tests/map-fleet-journey.mjs` 用隔离存档、真实服务端时钟和实际派遣按钮跑完整出征，检查自动交战、舰船持续运动、共用特效、舰桥相机、权威驾驶与释放、近景缩放，以及返航入库；不跳时间、不重结算正式存档。完整录像和截图写入 `output/playwright/fleet-journey/`。

驾驶与自动驾驶修正（2026-10-16）：星图驾驶使用每帧本地预测并向权威快照平滑校正，同一预测姿态用于舰体和相机。HUD 与服务端共用射程、朝向和星球遮挡判定，展示目标距离、武器射程、冷却与实际发射反馈；点按射击会排队，发送后保持至少 150 毫秒，避免网络请求阻塞或两次输入挤在一个模拟步内丢失指令。未装备的导弹按钮隐藏。

AI 不再将对方的新高度叠加为自己的目标高度；维持相对初始阵位的有界高度。炮塔型主力舰在有效射程且无遮挡时保持平稳舰体，固定主炮舰仍转向对准。只在新目标明显更合适时换目标；剩余敌军超出原阵位可覆盖范围时重新接敌。`tests/pilot-experience.test.mjs` 与 `tests/pilot-experience-browser.mjs` 验证长时 AI 稳定性、远处残敌、开火反馈、慢网络、快速换船、双击接管及相机同步。所有浏览器验收使用独立端口和临时存档。

曲速过渡性能修正（2026-10-16）：入场前准备曲速着色器、GPU 缓冲区与背景纹理，出入曲速时复用顶点缓冲区，直接计算光环与拖尾顶点，减少逐帧临时数组和垃圾回收。光环分段、拖尾数量和过渡时序保持一致。`tests/warp-effects.test.mjs` 验证缓冲区复用和阶段切换；`tests/warp-performance-browser.mjs` 在独立存档中真实派遣 44 艘混编舰队，采集完整出征的帧耗时与 CPU profile。当前电脑无头 Chrome 的进入／退出曲速渲染中位耗时从 11.6／13.4 毫秒降至 4.7／4.2 毫秒；对比记录位于 `output/playwright/warp-performance/comparison.json`。
