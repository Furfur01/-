# 轨道车间与舰船建造动画

在「造舰」页选择正在生产的舰型，会自动进入装配车间近景。「查看舰型」返回完整模型预览，「查看建造」回到实际队列；仍可拖动旋转、滚轮缩放。太空电梯全景和轨道造船厂入口保留。

- 太空电梯主泊位为开放车间：双侧服务平台、桁架、桥式吊机和四台焊接机械臂，无人物。
- 舰体采用图鉴中的真实模型，按承力结构 → 动力与设备 → 外壳封装 → 武器与附件 → 系统联调施工。原始网格保持完整、固定在安装位置，按功能层平滑显现。
- 起始阶段显示按舰体尺寸布置的钢制纵梁和肋框；外壳封装后框架退出。吊机在设备阶段搬运机组、封装阶段搬运装甲板，联调阶段停止焊接并点亮舰体灯光。旧式单网格模型使用定位框架到完整外壳的过渡。
- 每艘完工后离坞，批量生产接续下一艘；几何复用，淡入和通电材质独立，下一艘施工不会影响上一艘。
- 进度按服务器当前单艘的 `end - each * 1000` 计算，不使用整批开始时间。动画只读取队列，不创建舰船或修改存档。
- 月球旗舰中心读取独立的 `flagshipQueue`；普通船坞读取 `shipQueue`。防御设施和导弹不显示为舰船。
- 太空电梯自身初建时从地面逐步向上显露，施工桁架沿高度移动；升级时保留现有建筑。空闲时吊机归位、焊接停止。

## 源码与检查

- `scripts/universe/orbital-workshop.js`：车间、吊机、机械臂、施工桁架。
- `scripts/universe/ship-construction.js`：真实模型功能层、定位框架、批次内几何复用、离坞与资源释放。
- `scripts/universe/construction-frame.js`：从原舰体轮廓取尺寸，生成少量实体肋框与纵梁。
- `scripts/universe/ship-construction-state.js`：单艘进度与阶段名称。
- `scripts/universe/aurora-world-surface.js`：正式星球模型、施工显露和近远景接入。
- `client/command-p0/Stage.jsx`：建造/舰型切换。继续使用现有持久三维视口，不新增渲染器。

只重建本功能的前端产物：

```powershell
node scripts/build-world.mjs
node scripts/build-command-p0.mjs --ui-only
```
