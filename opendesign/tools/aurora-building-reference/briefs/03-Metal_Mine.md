# 金属开采综合体 · Metal_Mine

参考图：`images/03-Metal_Mine.png`。同时使用总说明《给GPT6Pro的建模说明》。

## 必须保留的辨识轮廓
黄色大钻臂＋粗壮破碎料斗。

## 主体拆分
- 钻臂、转轴与钻头
- 破碎料斗及精炼主机
- 短输送带
- 金属仓储舱（Metal_Storage）

## 小型周边设施
- 检修车间
- 装运站
- 控制室

保留左侧主视角中的相对位置与紧凑关系。主楼明显大于配套，配套各有形状、用途；不要只交一栋主建筑。

## 活动部件与结构
钻臂各关节、旋转钻头、输送带、装运吊具分别建模；矿体是独立资源模块。

## 本件交付
可编辑源文件、`Metal_Mine.glb` 和同角度渲染图；主体、周边设施与连接件分组。原 ID 不变。
