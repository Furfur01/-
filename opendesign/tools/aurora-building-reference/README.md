18 张 imagegen 建模参考板：14 类行星设施＋4 类月球设施。每张包含大幅主视角和正面、侧面、顶部辅助视图。

## 直接交给建模者

1. 从 `images/` 选一张设施图。
2. 同时提供 `给GPT6Pro的建模说明.md` 和 `briefs/` 中同编号的说明。
3. 先看研究所模型的轮廓、色块和配套位置，再批量制作其余类型。

打开 `index.html` 可浏览全部原图。三类储藏设施已画进对应矿场。

## 文件

- `images/`：18 张完整分辨率 PNG，含周边配套的新版本。
- `briefs/`：每类设施的主体拆分、配套和活动部件说明。
- `给GPT6Pro的建模说明.md`：整套造型与模型交付要求。
- `references/`：早期 AURORA 星球截图及生成时使用的单体渲染风格参考。
- `prompts.json`：内置 image_gen 的实际生成提示词。
- `flagship-revision.json`：旗舰中心浮空改版及舰体轮廓修正的生成记录。
- `manifest.json`：最终图片、设施 ID 和采用的造型信息。太阳能采用成图中的四翼构型。

生成方式：内置 image_gen；2026-10-19。所有参考板都已检查主体辨识度和周边配套。辅助视图用于造型参考，统一三维结构时以大图为准。
