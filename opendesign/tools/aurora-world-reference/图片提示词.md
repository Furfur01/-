# AURORA 星球图片提示词

使用方法：附上 `references/aurora-original-global.png` 作为**画风、颜色、体量**参考，附上已完成模型的渲染图作为**建筑造型**参考。每次使用下方“共同提示词＋一个星球专用段”。不要继承旧原图的圆形地台。

## 共同提示词

生成一张 AURORA 卡通太空策略游戏的完整星球概念图。严格延续参考中原版 AURORA 的设计语言，不重新设计美术：简单直观的大轮廓、干净的 Lowpoly 平面分色、明确的主体和少量小型配套设施。灰白建筑 #e1e4d7，深蓝结构 #22374d、#466277，暖金机械 #ffbd53，青色能源 #58ebd3，紫色晶体 #a14ce0。深海 #075779、浅海 #208f9b，草地 #68a765、#447f52，沙岸 #d8c68b，雪 #e5ebe4。只在对应环境使用自然色，不让熔岩星和红岩星也长出类地海洋。

画面为横向 3:2，深蓝黑太空背景。左侧约三分之二展示完整球体轮廓，右上展示一处模型与地形的接合近景，右下展示背面地貌方向。建筑从近侧延伸到远侧地平线，能看出整个星球都在建设。建筑足够大，在整球画面中可凭轮廓辨认用途，配套小而紧凑，地貌在机构之间连续通过。使用柔和明确的日光、干净阴影和少量能源亮点。

先构成一颗完整而连续的自然星球，再让现有模型因地制宜落位。保留参考模型的识别轮廓，不随机替换成新楼。道路连接入口与实际物流流程；矿场贴矿壁，雷达在开阔高地，工业设施有货运关系。每组机构不共用同一个模板。只在真实建筑脚下出现必要的薄基础。

禁止：建筑群周围的圆形地台、圆形土地贴片、统一环路、石头围圈、棋盘式碎石、等间距撒楼、独立展示底座拼成星球、统一大小的复制方块、写实噪点、复杂细碎工业纹理、厚重雾气、刺眼泛光、把所有设施缩得看不清。

画面只放少量英文标题，不放解释大段文字。

## 01 类地星：海湾与分水岭
标题 AURORA / TERRESTRIAL。弯曲但不对称的大陆围绕偏心内海，长短不一的海湾与河口、连贯山脊、坡麓森林和浅色沙岸。沿海低地放主基地和研究所，矿山镶在自然山脚，能源设施沿开阔缓坡布置，生态设施靠水源，仓储与装运设施靠运输通道。建筑与植被共享同一块自然地面，海岸直接经过机构附近，没有圆形清场。近景重点显示平面建筑接入起伏坡地的方式。

## 02 金属岩星：玄武岩与熔岩裂隙
标题 AURORA / METAL WORLD。深灰玄武岩球体，偏心火山群、分叉而非等距的橙红熔沟、大小不同且彼此连通的冷却岩台。金黄钻臂和处理设施嵌入真实矿壁；主基地、研究所与工业设施落在宽阔稳定的岩台，跨沟桥梁只出现在必要的物流连接处。设施之间是连续粗犷岩地，不能一个建筑配一块圆台。没有蓝色海洋，没有露天草坪或树林，绿色只在密闭温室内。

## 03 火星岩星：高原与紫晶裂谷
标题 AURORA / CRYSTAL RIFTS。温暖赤色和陶土橙的完整岩质星球，一条主要大裂谷及不对称支谷切开高原；晶体沿断层在不同高度成簇露出。谷底、崖壁与高地要有连续地质关系。开采、分选、成品转运顺矿脉通到谷口，主体建筑在稳定崖顶，桥梁跨越局部窄谷。不出现同心圆矿坑模板、圆形园区或一圈圈小晶体。没有海水和类地森林。

## 04 气态巨星：云海上的浮空设施
标题 AURORA / CLOUD WORLD。奶油白、铜橙与蓝灰色的宽阔流动云带，一处偏心大风暴和少量小涡旋，云面采用简洁 Lowpoly 色块而不是写实烟雾。球体没有陆地、山、海岸或铺装地面。所有设施在云顶上方悬浮：按功能组织的开放式框架、条形甲板、分组舱体，短桁架连接主建筑和小配套，能看到下方云层以及青色悬浮装置。不要统一圆盘浮台，不要在浮台上堆一座假山。保留现有工业设施轮廓，原料处理模块采用平台化接口。

## 05 月球：低重力重型装配
标题 AURORA / LUNAR FOUNDRY。灰白月壤、大小不等且相互叠覆的陨坑、深色月海和断崖。四种月球设施分布在全月面：三瓣密闭月球基地、双弧深空雷达、六边形虫洞发生器、浮空旗舰制造中心。普通设施使用小范围实际接地基础，不抬起一整块圆形园区。

旗舰中心整体离地悬浮，两侧粗壮装配轨之间是一艘半成品深空吞噬者，装甲只装了一部分，露出内部骨架；周边四个小型服务浮舱。船体前部宽、后部窄，前端为宽大的分叉轮廓，禁止画成长针尖舰首。场景展现低重力巨型装配，不是地面船厂。舰体与施工轨各自独立，中央没有整块实体地板。需要附上 `references/Flagship_Center-shape-reference.png` 锁定形状。

## 06 同类星球也要完全不同
标题 AURORA / ONE BIOME, THREE WORLDS。同一幅横向图中并列三个等尺度的完整类地星球，画风、光照、建筑模型和配色一致，差异来自地形结构：
- SEED 1047：两块不对称大陆，宽阔弯月形海域，一条明显分水岭，少量近岸群岛。
- SEED 2819：海洋占主导，分散岛链与一座马蹄形大岛；设施集中在适宜海峡与岛屿缓坡。
- SEED 7361：大面积连通大陆，偏心的肾形内海，山脉集中在一个象限，深河口与长半岛。
不能将同一地图旋转、镜像或换色。每颗的大陆连通性、海岸轮廓、水系、山脉走向和建筑选址都不同。仍然禁止圆形地台。上述 seed 只作为概念标签，不表示程序已经生成这些结果。
