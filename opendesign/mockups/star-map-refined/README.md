# 银河帝国 · 原版界面与精修按钮

打开 `index.html` 即可使用，不需要游戏后台，也不需要登录。

- 顶部框架、右侧星系景观、五颗行星、资源条、轨道图、雷达和布局沿用用户原版 demo。
- 保留新版弧形航线和按钮样式；另按参考 `concepts/star-map/index.html` 移植母星的金色脉冲、旋转方框、名称及悬浮提示卡。原版面板不变。
- 点击星系查看详情；右侧五颗行星可以切换。左栏和底部按钮打开原版功能概览。
- 在「显示设置」调整星点密度和冷蓝／银白色调。默认密度为 76%。
- 舰队面板中点击深空巡航或星际运输编队，定位目的地并高亮对应曲线。
- 键盘：`F` 查找、`H` 母星、`R` 全景、`+` / `−` 缩放、`Esc` 关闭浮层。聚焦星图后用左右方向键切换星系。

## 源文件

`interface.css` 保留原版样式，末尾集中放置按钮精修及必要的响应式规则；`interface.js` 管理界面状态；`galaxy-map.js` 管理星图、弧线与显示参数。

背景使用游戏现有 `galaxy-barred-b.points.bin` 的 76,872 个星点，经稳定采样和重新着色绘制。`assets/star-catalogue.js` 是该点目录的本地封装，不是背景图片。原始点位与正式游戏未修改。

星系名称、资源、概览内容及行星程序化绘制沿用用户提供的 `银河帝国_交互UI.html`，仅供界面展示。按钮使用上一版的 Lucide 图标与状态样式（ISC，见 `assets/lucide-LICENSE`）；航线保留参考稿启发的虚线弧线和移动方向标记。母星提示沿用参考稿造型，名称与坐标仍对应此 demo 的天穹星系和天穹一号。

这是独立设计产物，不包含在现有发行包的收集范围内。
