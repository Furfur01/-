# 银河帝国 · HTML 项目

当前候选版本为 **v0.1.0-alpha.1**。发行说明与准备状态见 [发布准备](docs/releases/PREPARATION.md)，玩家安装步骤见 [开始游戏](docs/releases/PLAYER-README.md)。尚未打标签或上传发行包。

双击桌面 **银河帝国启动器** 或项目内 **`银河帝国.cmd`**（旧入口 `启动HTML版.cmd` 也可用）。启动器是独立的后台监控窗口：打开后自动连接已有后台；未运行时点击“启动后台”，点击“进入游戏”打开浏览器。**关闭监控窗口不会停止后台**，需要停服时点击“保存并关闭后台”；更新后点击“重启后台”，会先保存进度、等原进程退出，再自动启动。重启期间按钮暂时禁用，完成后可刷新游戏页面；保存失败或原后台未退出时不会强行启动第二个进程。窗口每秒刷新进程、运行时长、存档路径、最近保存时间、当前账号和日志，提供已有账号切换；切换后游戏页面会在下一次刷新时同步。账号列表只包含当前宇宙中的玩家，不包含机器人；首次进入游戏才会创建账号。一个端口只打开一个监控窗口。

游戏地址：http://127.0.0.1:8289/ 。需要本地 Node.js 服务，不能直接双击 HTML 文件。正式星图与星球共用 Three.js 世界，运行素材均保存在本地。命令行打开启动器：`node scripts/launch-html.mjs`；只读检查状态：`node scripts/launch-html.mjs --status`；只读检查页面和接口：`node scripts/launch-html.mjs --check`。`/api/health` 提供不创建账号、不推进游戏的健康检查。开发时 `npm start` 启动的后台同样可以被监控窗口连接和关闭。旧版后台需先通过旧启动器保存退出，再启动新版。正式后台日志位于 `output/galactic-command/server.log`；使用独立存档的测试后台默认写入该存档旁的 `.log` 文件。

## 保留内容

- `opendesign/mockups/galactic-command/`：当前 HTML 界面、三维星球、建筑工坊、ASTRAL 星图与舰船机库。
- `opendesign/mockups/galaxy-empire/`、`client/`：旧网页源码及当前仍共用的图片、原版音频和图鉴资源。
- `game/`、`server.mjs`：游戏数值、经济规则、Node 战斗结算与本地 API。
- `data/universe.json`：原宇宙进度；`data/session.json`：原账号；其他存档备份也保留。请勿公开分享 `data/`。
- `scripts/`、`tests/`：HTML 构建、解包工具及验证；舰船可编辑源文件在 `scripts/hangar-source/`。
- `research/apk/`、`output/apk-icons/`、`output/apk-inspection/`：APK 原始解包包体、图集、TFS、Lua 字节码、文本与恢复索引。
- `research/`：HTML 数值依据、素材来源及参考资料。
- `models/generated/apk-buildings-v1/` 和同名 ZIP：本轮制作的 12 个建筑模型及预览图。
- `output/`：保留下来的 HTML 检查、截图、运行日志和本次清理清单。

银心探险：在连续星图中点选外围 / 内层 / 深层，固定海盗，分别探索 15 / 30 / 60 分钟；资源、普通舰船与暗物质奖励，可保存编队并选择 1 / 3 / 6 / 12 轮。出现战损或撤退即停，不自动补船，没有随机全损。小行星带已提供采矿入口，作业 30–120 分钟。通过启动器「重启后台」并刷新页面生效，详见[探险与采矿规则](game/black-hole-exploration.md)。

暗物质：顶部余额或底栏「暗物质」可进入加速与兑换。每 30 分钟剩余工期消耗 1 暗物质，可完成当前建筑、研究或造舰 / 防务 / 旗舰批次；原物资兑换继续保留。探险所得返航后入账，收支可在面板查看。更新后重启后台并刷新页面，详见[暗物质说明](game/dark-matter.md)。

2026-10-19：速射改为范围溅射倍率，未列目标和倍率 0 免疫溅射，直接命中仍正常受伤。普通武器默认溅射半径 60 空间单位；对某目标的暴击率为 1 − 1/r（r 为原速射值），暴击伤害固定 ×2。r 为 0、1 或未列出时不暴击；无溅射关系的武器半径为 0。爆炸冲击波显示真实半径，暴击不扩大范围。见 [溅射与暴击说明](game/damage-amplification.md)。保存并重启后台，再刷新页面生效。
