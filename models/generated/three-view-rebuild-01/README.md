# 两舰三视图全新重建 · 2026-10-13

根据用户要求，两艘从空白几何重新建模，不加载、变形或复用上一版舰体。仅复用现有材质、几何基础函数与已确认的低矮炮座。入口为 `opendesign/mockups/galactic-command/ships-three-view.js`。

参考为 `models/recovered/tripo-originals-20261013/` 找回的原始 Tripo GLB。原始驱逐舰先绕竖轴旋转 -90°，统一舰首方向；原模型纵向舰长归一为 14 展示单位，新模型按这个尺度建造。Blender 相机使用相同正交尺度 17，正面、侧面、俯视没有分别缩放。深空吞噬者展示倍率 2.8 在比对时解除，不代表 APK 米制尺寸。

- 驱逐舰：窄长主舰体、前侧舱、中段外伸舱、分层尾部；直展厚尾翼下倾，每侧两个沿翼展排列的圆形风扇。保留双等离子炮与 6 座近防炮。
- 深空吞噬者：三角形舰首截面、宽直前半船体、倾斜高舰首、内收折弯前支架、收窄后颈及横桥。超巨型非战斗旗舰，无主炮，14 座近防炮。

`*-comparison.png` 上排是找回的原模型，下排是新模型，均为正交投影。`*.png` 为页面透视预览；`*.glb` 为可导入的模型；`manifest.json` 包含 APK 身份、面数、尺寸及 GLB 导出再导入检查。
