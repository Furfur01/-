# 野怪星球 · APK 造型模型确认 v1

2026-10-15。造型确认包；本版模型已按用户确认接入正式游戏，详见项目 game/npc-planets.md。

| 文件 | 暂定用途 | APK 参考 | 核心造型 |
|---|---|---|---|
| outpost.glb | 废弃前哨 | 18 | 灰白岩壳、真实凹陷裂谷、暗橙核心 |
| garrison.glb | 赤铁守备站 | 20 | 黑红球面装甲、发光通路、小型防御节点 |
| charon.glb | 卡戎舰队 | 19 | 紫色球壳、径向发射节点与能量矛 |
| cargo.glb | 遗落货仓 | 28（同属 23 的机械球方向） | 分瓣仓壳、外翻舱门、内部货箱 |
| fracture.glb | 苍穹裂隙 | 34 | 分离上下壳、内部核心、蓝色裂环、圆形接口 |

这些是参照解包图重新制作的真实三维网格，不是 APK 中提取的原版 3D 模型。野怪与图案的对应为项目设计，APK 未提供这种固定映射。34 已确认用于 Lv 5「苍穹裂隙」。

## 查看

在项目根目录运行：

```powershell
node models/generated/npc-planets-apk-v1/serve.mjs
```

打开 http://127.0.0.1:8395/ 。上方五款并列，点击切换大图。拖动旋转、滚轮缩放，可暂停自转、查看线框、复位及下载 GLB。右侧展示对应 APK 原图。

## 编辑与重建

`models.js` 是完整可编辑几何源。所有造型都是顶点、曲面装甲、管线、破口和实体配件，没有平面贴图冒充模型。局部半径约 1，Y 轴向上；材质使用 glTF 支持的 PBR、发光与顶点色。

```powershell
node models/generated/npc-planets-apk-v1/build.mjs
```

该命令重新生成五个 GLB、manifest.json 和独立预览脚本。每个 GLB 导出后重新载入，核对网格数量、三角形数量与有限坐标。

目前为造型确认级模型，未添加游戏状态、战斗属性、LOD、碰撞体或正式星图切换逻辑。蓝色裂环和能量矛为可导出的静态网格；预览自转由查看器提供。
