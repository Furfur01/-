# 银河帝国 · APK 建筑模型首批

12 座可编辑的真三维建筑，按项目内 APK 解包原图的可见轮廓和功能部件重建。

包含金属矿、晶体矿、气体矿、太阳能电站、金属仓库、晶体仓库、气体仓库、机器人厂、飞船基地、研究实验室、雷达站、核电站。

每座提供标准 glTF 2.0 二进制 `.glb` 与 Three.js 实际渲染的 `.png` 预览。`manifest.json` 记录名称、结构特征和文件对应关系。

- GLB 为静态网格，可直接导入 Three.js、Godot、Blender 等；无需外部贴图。
- 坐标为 Y 轴向上，原点位于建筑基座中央，统一约 1.7 × 1.5 的局部占地。导入后按场景比例缩放。
- 使用独立材质表现深色壳体、玻璃、铜管、晶体和发光部件；光照由目标场景提供。
- 网页中部分机械有旋转动画；本批 GLB 未包含动画轨道。
- APK 原图没有提供的背面与内部结构为补建，不声称还原原始三维资产。
