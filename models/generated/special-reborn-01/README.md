# 收割者与湮灭之星重置 · 2026-10-13

本次按用户授权从新几何重做两舰。原始模型、旧生成 GLB 均保留；变更前路由和建模源备份在 `models/archive/before-special-rebuild-20261013/`，更早模型可在舰船档案切换“保留的现有模型”。

## 收割者 / Reaper

黑曜陶瓷与暗金承力骨架，前钩镰翼轮廓，嵌入式约束核心，三组相位喷口。22244 三角形，33 个网格。舰长比例暂定 90。档案采用带轻微虹彩的粗糙陶瓷材质；原生飞行渲染器使用相同颜色、几何和发光分区。

双束相位收割蓄能 1.1 秒，前向射界内持续切割最多 1.25 秒；炮口约束环和螺旋光丝连接到实际炮口，命中时回收护盾，护盾上限 100%。2 座旋转副炮、2 座近防炮、4 个向上发射的导弹口。APK 原说明中的湮灭免疫仍保留。

## 湮灭之星 / Annihilator

无人反物质自行导弹，没有驾驶舱和炮塔。12252 三角形，9 个网格。比例暂定 8；可从外部观察、驾驶调整方向，锁定目标后按 Space 自行突击。失去目标安全自毁，不造成范围伤害。

引爆分为约束场内缩、白热核心、三层倾斜冲击环、湍动能量壳和径向余辉。范围伤害随波前推进，每个目标只结算一次，按距离衰减，忽略护盾储量；收割者免疫。演练伤害半径 680 世界单位（HUD 6.8 km），中心伤害 180。爆炸后自动切换广角观测，5.2 秒后补充新演练弹。

新增尺寸、推进技术名、收割机制、伤害与护盾回收均为原创演练设计，不是恢复出的 APK 数值；不写入战略战斗结算和经济系统。原 APK 文字及社区数据保留在档案。爆炸为程序化视觉，不模拟真实反物质物理。
