# APK 原始图标名称校对

这份对照表以用户给出的原始图集和本项目已解包的 `yinhediguo.apk` 为依据。没有重新绘制图标，也没有用外形猜测编号。

- [舰船名称对照图](fleet-names.png)：19 枚已提取飞船／卫星图标。
- [防御设施名称对照图](defense-names.png)：9 枚。
- [交互核对页](index.html)：原图编号定位、分类查看和数据下载。
- [CSV](name-map.csv) 与 [完整来源 JSON](name-map.json)。

## 核对方法

1. `output/apk-icons/icons.json` 记录 `Fleets.tfs` 的 `type_*` 帧、原始图集和裁切坐标。
2. `output/apk-icons/lua-analysis/GameFleetDefine.json` 的表赋值记录确定编号与 `FT_*` 舰种常量的对应关系。
3. `menu.idx` / `menu.cn` / `menu.en` 和 `building.*` 提供描述、别名与特殊舰名称。
4. 逐张检查已提取图标与原始图集对应像素完全相同；用户剪贴板图的透明通道和不透明像素也与 APK 图集一致。剪贴板改变了透明区域的隐藏 RGB，因此不声称整份 PNG 字节相同。

中文基础舰种采用当前项目与带名称截图的习惯称呼。特殊舰名称来自 APK 本地文案：`interceptor` = 裂变者，`TSZ_NAME` = 深空吞噬者，`GC_fleet_type_25_description` = 噬能截击者，`GC_fleet_type_26_description` = 钛能守卫者。`Reaper` 的英文在描述中明确出现，中文“收割者”暂译，未冒充原版正式中文标题。

用户给出的 `ShipCityTech_1` 图集共 29 枚图标：17 个飞船／卫星，9 个防御设施，以及超空间科技、脉冲引擎和计算机科技 3 个科技图标。APK 中另有 `type_28` 湮灭之星和 `type_29` Reaper，来自独立图集，故舰船对照图合计 19 枚。

`FT_DEAD_STAR = 8` 常量存在，但当前提取的 `Fleets.tfs` 图标表没有 `type_8` 图片，不能把其他舰船套成死星。该表也没有 `FT_GUARDIAN` 常量；`type_26` 明确是钛能守卫者，不能直接把它当作旧模型清单中的“守护者”。原始代码拼写 `FT_BATTLEECRUISER` 保留不改。

此前根据宣传缩略图重绘的三张草稿已经标记为 `draft-before-atlas`，不再作为建模定稿。下一版战列舰的唯一图标来源是 `icons/fleet_04_Battleship.png`。

重建本对照表：在项目根目录运行 `python scripts/map-apk-fleet-icons.py`。脚本只读取已有解包目录，不修改另一任务的解包产物或现有游戏素材。
