# KEEL 四型驾驶舱

模型来自用户提供并要求接入的 `KEEL_Dreadnought_Interior.html`。
原文件 SHA-256：`6915efce4f02f69a3b0fd23312ac5e884eb56ae9bba7cbaf7d33f0271494d631`。

- `interior.js`：基于原建筑与设备的游戏适配，包含环境反射、灯具和四个空挂点；无 DOM、输入、星空、独立循环或玩法。
- `seating.js` / `aft.js`：原座椅与后舱壁建模源码。
- `room.js`：游戏中型舰桥的接入层，沿用原驾驶坐标和互动逻辑，独立恢复PBR色彩、曝光与阴影状态。

游戏 `horizon` 类统一使用此模型，当前战斗舰包括巡洋舰、战列舰、轰炸机、无畏舰与驱逐舰。独立融合靶场也复用同一中型模型。

全舰队入口由 `game/ship-cabins.mjs` 统一分配，图鉴靶场、独立战场、连续星图实战与历史回放使用同一规则：

| 内饰 | 舰型 |
| --- | --- |
| KESTREL 战机 | 轻型战机、重型战机、钛能守卫者 |
| KEEL 中型舰桥 | 驱逐舰、巡洋舰、战列舰、无畏舰、轰炸机、轻型运输舰、重型运输舰、殖民舰、回收舰、守护者 |
| BASTION 巨型舰桥 | 裂变者、噬能截击者、收割者、死星 |
| FLEET COMMAND 旗舰 | 深空吞噬者，保留真实蜂群指令与补充状态 |

靶场加载全部 21 种舰船的原模型，不再把运输舰、死星或守护者回退到默认驱逐舰。18 种有座舱舰船共用上述四套已批准内饰；无人探测器、太阳能卫星、湮灭之星、召唤蜂群及地面防御设施使用外部观察。民用舰桥可观战，服务器原有手动驾驶权限不变。换舰会重置座舱眼位、环视、行走和仪表缓存；舰船位置、真实血量与游戏结算不由驾驶室修改。防御简图取对应舰型的模型轮廓。

靶场和实战使用同一 `layout.bridge` 眼位与完整原舰体，已删除靶场压扁舰艏的替身几何。球形死星通过 `shipCabinSeat` 将观察点放在球体前侧，避免屋顶通用眼位让球面占满前窗；这仅调整镜头锚点，船体与护盾的网格、位置和命中坐标不变。

另外三型来自用户提供的 `KEEL_Fighter_Interior.html`、`KEEL_Battleship_Interior.html`、`KEEL_Flagship_Interior.html`，分别由 `fighter.js`、`battleship.js`、`flagship.js` 保存可编辑建模源码，`family-common.js` 提供材质、灯光、合批和资源释放。只接入室内几何与灯光，不导入原文件的独立 HUD、控制器或动画循环。原文件 SHA-256：

- Fighter：`280d40393bded1507c3cd03b4a9f8128ef1142ab638fb0cccf740769fd11f1f5`
- Battleship：`4c22f116d3bdc20f0017cdc259b972c5370c42db36b5e4f3431f2a391ad4738b`
- Flagship：`b22423844941c69137e6afb15c809d7348aad31e8023ca12546daa345ae8c3d3`

战斗机使用 KESTREL 内饰和独立 `FighterHUD`。`fighter-instruments.js` 按原显示器挂点的完整旋转和宽高比贴合三块实体屏：左侧扫描、中央姿态/速度/高度、右侧发动机/护盾/舰体刻度。实体屏保留少字的航空仪表风格。两侧全息使用原融合版防御/火控源码，上方分别为导航/武器状态；舱内隐藏重复的平面速度与护盾大条，外视保留。

大型 `bastion` 类使用 BASTION 内饰；拥有 carrier 属性的旗舰（包括深空吞噬者）使用 FLEET COMMAND 内饰，仍沿用 bastion 的飞行控制。旗舰左屏保留蜂群战术、阵型、集火和自动补充状态。真实生成与指挥仍由原游戏规则决定。舰船外形、尾焰、爆炸和武器效果未由室内模型替换。

`walking.js` 使用实际楼板、台阶、座椅和设备几何进行移动碰撞。三个新模型按材质合批后约 60 / 67 / 71 个几何批次；大厅全息雷达直接嵌入模型原桌台，不重复生成底座或圆锥。

原模型眼位 `[0,1.6,.95]`，当前提高到 `[0,1.8,.95]`，米制，Y向上、-Z向前。游戏平移模型以对齐原视点 `[0,3.8,-1]`，避免影响操舰、瞄准和视角偏移。融合靶场相对于驾驶员坐标导入。全息屏、雷达和顶部镜头由各使用方挂接，不在模型里生成第二套HUD。

此前完成的视野调整继续保留：中央三窗为8.28×3.75米连续前窗，窗下墙0.62米，侧窗加高；前斜撑外移0.85米并缩减截面；吊屏80%并上收，左右操纵台外展、前移和降低。融合预览保留64°视角，默认俯仰归零。本次仅修复仪表与反馈接入，没有重新制作中型或战机内饰。雷达恢复融合版低圆盘、扫描扇区和目标菱形，不生成大球体、笼状弧线或投影圆锥。

`status-display.js` 在三型舰桥顶部恢复实时外景屏与舱内警告条。`exterior-feed.js` 在绘制内饰前采集真实前向外景，星图模式合成行星与舰船图层；当前是前向光学画面，不是独立舰尾摄影机。`feedback.js` 恢复护盾蓝闪、舰体受击抖动、红色警报、灯光闪烁及火花；切舰、换战斗和回放跳转会重置损伤比较，避免误报。

双层护盾由正式共用 `renderer.js` 的 `shieldImpact` / `drawShield` 驱动：舰体层使用实际船体网格，外层使用 `game/shield-envelope.mjs` 从船体顶点计算的外包椭球。原融合版蜂窝扩散函数位于 `effects/shield-ripple.js`，游戏和融合预览共用。驾驶舱隐藏自身外壳时不再隐藏护盾；星图、独立战场、回放和靶场都从同一命中事件取得接触点。`keel/shield-impact.js` 仅负责实际舱内材质的短促蓝色补光，不在镜头前叠假护盾。

保留原PBR材质、程序纹理和灯光；原独立文件的全屏SSAO与暗角未移入游戏。几何按材质和语义组件合批，约2100个零件合成百余绘制对象。资源销毁覆盖几何、材质、程序纹理、环境反射和阴影贴图。

2026-10-20 已清理上述功能的独立测试与预览工具；当前统一检查范围见 `tests/README.md`。

正式驾驶舱仍可在舰船靶场与战斗中使用；四型独立预览已移除。
