# AURORA 园区共享模型

用户已认可全部 14 类紧凑太空机构，并于 2026-10-18 授权接入四种星球、替换正式渲染。这里保存该阶段的布局、建筑和设备模型；182 个建筑/设备角色由功能规划产生。模型保留主次尺度、专业轮廓、密闭连廊、运输轴和区间留白。

## 当时的接入

- `../aurora-district-layout.js`：使用原 `SURFACE_SLOTS` 的 14 个全球位置。角色、道路、入口、管线、施工顺序和实际数量来自本目录的独立园区方案。
- `height.js`：CPU、Worker、模型地基、道路和局部地形共同读取的确定性高度。
- `../aurora-district-model.js`：近景按材质批处理，动态运输车共享实例几何，最多缓存四个近景园区。远景保留各主体轮廓、专业设备和分区体量。
- `../campus-terrain-patch.js`：固态星近景使用与道路同向的两单位三角网格，地基不随全球 LOD 变化；外围地质过渡带接到当帧的全球三角网格。底层地形仅在已有局部网格的范围内裁去，防止初次加载吞没建筑或铺装穿插。
- `../continuous-surface.js`：在类地、熔岩、晶体、气态四类星球中保持相同布局和全球分布。气态全部 14 类使用按功能分组的浮台和连接桥，不生成地面山体。颜色和外围地质来自对应星球。
- 子建筑拾取回传原设施 ID；地面、电梯和轨道船坞继续使用原导航接口。建造按主体、专业设施、配套顺序展开，运输沿方案道路，暂停状态冻结生产动画。

这些文件只负责呈现，不改游戏设施名称、等级、成本、产能、科技、战斗、资源或存档结构。
