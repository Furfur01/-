# 战斗音效

刷新游戏后，战斗工具栏的「战斗音效」控制开关，旁边滑条控制音量。默认开启、音量 35%，与 UI 音效和背景音乐分开保存。浏览器首次播放需要先点击页面。

## 已接入的声音

- 19 种有武器舰型各自保留已确认的开火成品；深空吞噬者没有主炮，选定的连射声配给自卫炮。钛能使用轻型声音，原厚重钛能声给裂变者；收割者使用原湮灭之星的长束流；湮灭之星在实际引爆时播放电磁大爆炸。
- 普通舰体受击按舰型大小使用 Metal Stress，重伤使用更强的扭曲、撕裂声；护盾命中、破盾、舰体击毁分别触发。
- 当前观察的己方舰船首次降至 30% 舰体以下发出警报。普通命中不会播放整舰爆炸。
- 实时战场、历史回放和舰船靶场共用声音映射。暂停、退出战场或切到后台会停止战斗声音。
- 同一发炮的多个炮管事件合并播放；长束流不逐帧重放。远处声音衰减，全局最多同时 12 声，同一素材最多 3 声，优先保留当前舰船及重要提示。

## 素材与维护

运行素材位于 `opendesign/mockups/galactic-command/assets/audio/combat/`，共 32 个 WAV；`manifest.json` 保留原文件名和试听来源。运行游戏不依赖下载目录或试听服务器。

`client/combat-audio.mjs` 管理播放、舰型映射和受击事件。正式战场由 `map-combat.js` 接入，靶场及旧回放入口由 `scripts/three-flight/` 接入。受击事件增加护盾前后值和舰体伤害，旧记录仍可使用快照判断。

重新选型后用 `node scripts/import-combat-audio.mjs` 从已确认的试听清单导入，再运行 `node scripts/build-three-flight.mjs` 和 `node scripts/build-world.mjs`。导入保留原 WAV，不改变音高、速度或声音内容。

这些是用户提供的商业素材，不是开源音效；公开发行时按对应素材库许可随游戏打包，不单独分发素材库。
