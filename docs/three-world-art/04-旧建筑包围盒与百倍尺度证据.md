# 旧正式建筑包围盒与百倍尺度证据

基准取自迁移前正式星图使用的 AURORA 研究院单体。来源是 `opendesign/mockups/planet-construction-review/aurora-runtime.js` 的 `model('research')`，不是 `colony-v1`。旧 `buildDistricts` 对普通建筑施加 `bs = 2.7`；旧 `aurora-navigation.js` 的正式详情绘制再施加 `scale = p.radius / R`，其中 `R = 16`。

验收测试仅从上述文件提取原数学、几何和 `model` 函数，在不提供 DOM、WebGL、网络的独立 VM 中生成顶点。没有创建旧渲染器，也没有模拟旧 WebGL API。生成器产生 6,480 个顶点，每顶点 11 个数，前 3 个数是模型位置。

| 数值 | X | Y | Z |
| --- | ---: | ---: | ---: |
| 原模型局部最小点 | -0.982 | -0.245 | -0.6146 |
| 原模型局部最大点 | 0.982 | 1.502 | 0.92 |
| 原模型局部包围盒尺寸 | 1.964 | 1.747 | 1.5346 |
| 旧类地星显示包围盒尺寸 | 0.57999375 | 0.5159109375 | 0.4531865625 |
| 新空间同等单体显示包围盒尺寸 | 0.57999375 | 0.5159109375 | 0.4531865625 |

类地星原半径为 `1.75`，新半径为 `175`。旧研究院完整变换单位为 `2.7 × 1.75 / 16 = 0.2953125`；新空间保留这一单位。以包围盒最大边 `0.57999375` 为普通建筑单体的可复算尺度：

- 旧星球半径 / 单体最大边 = `1.75 / 0.57999375 = 3.01727389303764`。
- 新星球半径 / 同等单体最大边 = `175 / 0.57999375 = 301.727389303764`。
- 两个比例相除等于 `100`。星球扩大，作为比较基准的建筑几何和显示尺寸没有扩大。

`scripts/universe/terrain.js` 的 `LEGACY_ORDINARY_MESH` 保存原模型边界；`scaleEvidence(radius).ordinaryMesh` 同时输出旧、新的单位、完整包围盒尺寸和半径比例。测试覆盖半径 `175、140、154、224、28`，逐一验证同等单体显示尺寸不变、半径比例提高 100 倍。

新工业资产是由许多设备组成的建筑群，整体占地可以大于旧研究院；此基准衡量普通单体，不能把整座矿场、电梯缆索或包含轨道站的包围盒当作单体。当前过渡工业模型的基础单位是 `新星球半径 / 100 / 16`。外部美术接入时按此单位换算设备，并用本表复核尺度；最终外部美术尚待交付。

复算命令：`node --test tests/three-world-planet-surface.test.mjs`。该测试只读取源代码与生成临时内存几何，不访问存档、账号或游戏服务。
