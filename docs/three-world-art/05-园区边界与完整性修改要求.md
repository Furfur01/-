# 可直接转发：把现有工业模型完善成完整园区

请在已经完成的金属矿区、晶体精炼、气体炼化、浮空采气、太空电梯和轨道船坞模型上继续修改。现有设备尺度和工业规模已经足够，本轮重点是园区边界、入口、道路组织、功能分区与地形收边。保留现有可用模型，优先重排、复用，腾出必要空地，不用继续复制生产线来表现完成度。

你只负责独立模型与预览，看不到也不需要访问游戏项目。下面的要求完全针对交付模型；正式坐标、镜头、经营规则和资源管理由游戏方负责。

## 1. 从外部能认出“一个园区”

地面园区需要读得出的内外关系。沿实际场地边界组合使用围栏、低矮围墙、挡土、护坡、排水沟和外围巡检路，保留明确的道路与铁路出入口。围界应在常用斜俯视角下可辨，但尺度要与车辆、门和设备一致，不做巨型城墙。

在围界与主体生产设施之间留出一圈有用途的边缘空间：巡检、维修、绿化或裸土缓冲、管线和排水。外围不必全部采用相同处理，矿坑侧、物流侧与厂房侧应有所区别。

矩形或正交布局可以保留，但不能仅凭一张齐边裁切的地板表达边界。铺装外缘应衔接碎石、裸土、护坡或天然地形，避免一圈厚重底座。围栏也不能沿裸露地板边缘机械排一圈就算完成。

## 2. 有入口、有主路、有物流去向

每座地面园区设置一个清晰的主入口，以及按需要设置的货运或检修入口。主入口用门岗、园区标识、车道、检查或等候区形成一个完整节点；可以改造现有小建筑，不必另扩一大片行政区。

一条主要运输道路贯通入口、仓储、主要加工区和装卸区，支路连接设备和检修点。车道宽度、转弯空间、路口和停车位置一致。铁路或输送系统需要可见的进出园接口、装卸终点或回转设施，不能在模型边缘无解释地切断。

独立预览里给外接道路留出一小段，使人看懂园区如何与外部连接；无需生成整张星图或其他园区。出入口位置、方向和净空作为锚点交付，后续由游戏方连接运输线路。

## 3. 用功能形成分区和主次

既有阵列中应能区分采集或原料区、加工区、仓储区、装运区及公用设施。通过道路宽度、设备组合、铺装、空地、管廊与体块差异表达分区，不需要给每个分区再围一圈墙。

- **金属矿区**：保留矿坑这个主要地标。矿道与破碎筛分、输送带、堆场、装车区相连；矿坑边缘有护坡、警戒和运输组织。厂房不平均包围矿坑。
- **晶体精炼园区**：原料端、分选精炼主体、封闭仓储、成品装运形成连续布局。成片厂房要有大型主体、配套小楼和空地的差异，避免每格都是同一组设备。
- **气体炼化园区**：井场或进料端、压缩分离、储罐、运输区各有清楚范围；储罐区用围堰、检修道路和间隔表达独立区域，管廊沿主线连接。不要把每个单元都画成同一大小的棋盘格。
- **电梯地面港**：外围道路、铁路进港、货运编组、仓储、升降核心、维修区形成一个完整港区。升降核心有独立作业范围，普通车流不横穿升降设备。

可以从现有重复生产单元中调整出维修、控制、动力与车辆停放位置。增加建筑种类以功能需要为依据，不以更大的占地倍数或更多生产线作为本轮目标。

## 4. 浮空和轨道资产使用自己的边界语言

**浮空园区**以平台边梁、护栏、检修步道、结构支撑和桥头节点表达边界。平台之间的人员通道、货物通道和管线可追踪，并有明确的主要停靠口。保留平台之间的空隙和结构关系，不套用地面园区围墙。

**轨道船坞**保留开放桁架，以作业平台边缘、灯标、检修走道、停泊门架和净空标示明确每个作业区。运输桁架连接中央物流节点，进出港轴线不受设备阻挡。边界表达可管理的作业范围，不把船坞包成封闭外壳。

## 5. 交付和检查

保持原有模型工厂和独立预览分离。把外围设施、道路和边缘地形分成命名组，方便提取、隐藏和替换；重复围栏、路缘、灯杆使用共享几何或实例化。远景保留入口、主路和园区轮廓，不让细围栏产生闪烁。

保留原有 `footprint` 作为全部模型的外包占地，另提供 `siteBoundary: [[x,z], ...]` 表示地面园区实际围界，并提供主要出入口锚点 `{position:[x,y,z], direction:[x,y,z], width}`；全部使用模型局部坐标。浮空和轨道模块用各平台或作业区边界替代地面围界，不要求一个外圈覆盖所有空隙。

每个模型补三张图：俯视总平面、常用斜俯视、入口或边缘近景。总平面可以加可关闭的分区与物流箭头。即使关掉文字标注，也应看出园区从哪里进入、主要生产在哪里、物料从哪里出去、园区在哪里结束。

先用金属矿区完善这一套边界和道路语言，再应用到其他模型。新增首都另有独立任务；它增加目前缺少的功能建筑，本轮不要把所有园区重复扩成另一座首都。
