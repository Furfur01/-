# 可直接转发：独立制作矿场、选矿与炼化综合体

请用 Three.js 独立制作三类工业建筑群，交付模型生成代码、材质、可关闭动画、独立预览和说明。**你不需要访问任何现有项目、游戏源码、游戏 API 或现有函数，本文就是完整任务。** 可以自行组织代码与演示；重点是工业美术质量，以及把资产工厂与预览程序分开，方便我们随后提取使用。

你负责模型、局部地形、材质、动画和独立演示。我们负责正式游戏接入、建筑 ID 映射、真实经营状态、镜头路径、大世界坐标、星球表面定位和运行时裁剪。无需实现游戏经济、真实生产队列、星图或整颗星球。

## 三类工业综合体

类型使用通用名称 `metal / crystal / gas`，每类都要有一条能从空间布局读懂的物料流程。

1. **metal（金属）**：阶梯式露天矿坑、环形矿道、作业面、挖掘或破碎设备、粗碎/筛分、输送带、堆料场、仓储、卡车或铁路装卸。物料从矿坑经过加工进入成品仓，最后装车。矿坑在交付的局部地形内真实向下开挖，有底部、坡壁、台阶和能通行的矿道；不要用浮空圆环冒充开挖。
2. **crystal（晶体矿物）**：地质矿层或采掘工作面、破碎、分选、精炼、净化、封闭仓储。用小尺度矿脉、原料堆和加工设备体现晶体，不使用巨大装饰水晶柱。通过封闭加工车间、分选装置和精炼设备，形成有别于金属矿的流程与轮廓。
3. **gas（气体）**：井口阵列、集气管道、压缩机房、分离塔、换热或精馏设备、储罐、装车区和控制室。管道连接设备，支架有落点，阀组、维修通道和安全间隔可辨。另提供 `floating: true` 的浮空基座版本，保留相同生产流程，增加稳定设施、浮空支撑和向下延伸的采集管线；不需要实现飞行物理。

三类的仓储部分均为独立子组，可以单独展示。建筑应有基础、门、检修平台、扶梯、栏杆和设备连接，而不只是不同大小的盒子排列。

## 美术方向与模型尺度

采用矿业和石化工业的结构语言。主色为哑光灰、旧钢、灰褐土、暗蓝灰，少量安全黄标记危险边界。粗糙度和轻微磨损帮助区分钢材、混凝土、泥土与橡胶；状态灯少而清楚。远处靠生产流程和大体块辨认，近处能读出管廊、设备、路面和材料转运关系。

避免玩具建筑、统一圆形凸台、对称科幻宝塔、满地霓虹和巨大装饰晶体。地形边缘缓缓过渡，基础合理整平，不把整个综合体垫在一张悬空厚圆盘上。

园区必须有读得出的边界与入口：围栏或护坡、巡检道路、排水和边缘裸土共同表达内外关系；主入口和货运口连接贯通的物流主路。用设备组合、道路、铺装和空地形成原料、加工、仓储、装运分区。矩形布局可保留，但不能仅靠地板裁切线充当园区边界，也不能用均匀复制生产单元替代完整布局。浮空版本用平台边梁、护栏、步道、桥头与停靠口表达边界。

采用 **Y-up**，地面锚点为 `[0, 0, 0]`，X/Z 是地面平面。普通场地从 **6 × 4 模型单位**开始，矿坑可以扩大，但须返回实际占地边界。模型单位不宣称等于一米；保留 `root.scale = (1,1,1)`，不在工厂里另做游戏尺度换算。如需理解星球与设备比例，同一模型坐标下的参考星球半径为 1600；不要求你创建该星球，最终放缩由我们负责。

设备之间保持可信比例。例如普通运输车可长约 0.35–0.6、宽 0.15–0.25 模型单位；门、栏杆应明显小于车辆。重型采矿设备可以更大，但道路、转弯半径和装卸空间必须容得下。提供可关闭的车辆或人物比例参考。矿坑不能被一个储罐占满，塔器也不能缩小到失去工艺用途。

## 独立资产接口

交付 `resource-complexes.js`，导出 `createResourceComplex(options)`。参数只使用以下独立含义：

- `THREE`：预览传入的本地 Three.js 模块。
- `type`：`'metal'`、`'crystal'` 或 `'gas'`。
- `seed`：整数随机种子；相同参数生成相同布局。
- `size`：场地 X/Z 方向尺寸，默认 `{width: 6, depth: 4}`。
- `ground`：`{heightAt(x,z)}`，输入地面高度函数，返回模型单位，默认平地 `() => 0`。工厂可以在其基础上生成整地、道路和矿坑。
- `floating`：布尔值，默认 `false`；仅气体综合体需要浮空版本。

完整独立调用示例，路径均来自交付目录：

```js
import * as THREE from './vendor/three/three.module.js';
import {createResourceComplex} from './resource-complexes.js';

const asset = createResourceComplex({
  THREE,
  type: 'metal',
  seed: 17,
  size: {width: 6, depth: 4},
  ground: {heightAt: (x, z) => 0},
  floating: false,
});

asset.setVisualState({
  running: true,
  activity: 0.8,
  construction: 1,
  storageFill: 0.55,
});
asset.update(1 / 60, {visible: true, detail: 'near', animate: true});
// 预览将 asset.root 添加到自己的 scene；不用时先移除，再调用 asset.dispose()。
```

工厂返回以下内容；内部实现自由，但数据含义完整且不依赖项目字段：

| 返回项 | 约定 |
| --- | --- |
| `root` | 一个 `THREE.Group`，包含全部资产，以地面锚点为原点，缩放保持 1。 |
| `groups` | `{terrain, structures, equipment, storage, vehicles, effects, silhouette}`，每项为命名的 `THREE.Group`；无内容的组也保留为空组。 |
| `footprint` | `[[x,z], ...]`，包围局部地形和设施的占地多边形，至少 3 点，不重复终点。 |
| `bounds` | `{min: [x,y,z], max: [x,y,z]}`，整个模型的实际局部包围盒，含矿坑深度、浮空基座和最大动画运动范围。 |
| `anchors` | `{ground, view, loading, storage, entry}`；每项为 `{position: [x,y,z], normal: [x,y,z]}`，全部使用根组局部坐标，normal 是单位向量。ground 为基础向上法线；view 为推荐观察位置且 normal 指向主体；其他项为连接点的朝外方向。 |
| `heightAt(x,z)` | 查询生成后的局部地表高度，包括整地和矿坑；基础、道路和车辆使用同一结果。浮空版本查询工作平台，采集管线不算地表。 |
| `setVisualState(state)` | 接收下述外观参数；不产生资源、等级或队列。 |
| `update(dt, options)` | dt 为秒，options 为 `{visible, detail, animate}`，visible/animate 为布尔值，detail 为 `'near' / 'far'`。默认 true / near / true，只推进展示动画。 |
| `dispose()` | 释放实例拥有的几何、材质、纹理等资源，可安全重复调用。共享资源应正确处理引用。 |

`setVisualState` 的完整默认参数是 `{running: true, activity: 1, construction: 1, storageFill: 0.5}`。running 为布尔值；其余三个值为 0–1，分别表示设备活动强度、施工展示进度、堆料或储罐填充程度。running=false 停止作业，activity 可降低设备速度。预览可以使用滑块或模拟状态控制它们，不需要理解任何游戏的低电力、库存、升级或真实队列；我们后续负责状态映射。

输送带、运输车和泵的动画沿流程运行，有装载、移动、卸料和返回的关系。关闭动画或隐藏时停止运动；远景停止车辆、粒子与精细设备动画。恢复时不补播历史帧。车轮接地、车辆不穿设备、管道不跟随泵体扭曲，运动不超出声明的边界。

**资产工厂与独立预览分开。** `resource-complexes.js` 不创建 renderer、canvas、相机、RAF 或全局输入监听，导入时不自动运行演示。`preview.js` 可以自由创建自己的场景、相机、renderer、循环、鼠标控制和模拟状态 UI。正式游戏中的相机、渲染和裁剪由我们接手。

## 独立预览与交付

默认完全离线运行。交付 `resource-complexes.js`、`preview.js`、`preview.html`、全部本地纹理或程序化材质、README，以及本地 Three.js 依赖。默认使用 **Three.js 0.184.0**，`vendor/three/` 包含实际使用的 ES Module、`three.core.js`、所需 addons 和许可证；说明完整依赖清单。不要假定作者或接收者能访问项目的 node_modules，不使用 CDN、远程图片、远程模型、账号或网络 API。

README 写清版本、文件结构、本地静态 HTTP 启动命令和浏览器地址。例如已装 Python 时在交付目录运行 `python -m http.server 8000 --bind 127.0.0.1`，打开 `http://127.0.0.1:8000/preview.html`，无需下载运行时依赖。若使用 OrbitControls 等 addons，应附正确的本地 import map 或相对路径配置。

预览提供三类切换、固定种子 **17 / 42 / 101**、气体地面/浮空切换、近景/远景与动画开关，以及全部外观参数控制。模拟运输车、原料和状态可以自行制作，并清楚标为演示。可以环绕建筑、观察矿坑深度与装卸动作，用预览壳的灯光检查顺光、逆光和夜景，不需真实游戏数据。

重复储罐、支架、护栏、管件和零件尽量共享几何、材质并使用 `InstancedMesh`，不要给每个设备配真实光源。高细节以每综合体 60 draw calls、15 万三角形为参考上限，远景轮廓争取 1–4 draw calls；报告实测值、三角形数和动画对象数。优先使用 Three.js 标准材质；自定义 shader 遵循 Three.js 的色彩输出和对数深度约定，不重复应用曝光或 Gamma。灯光、曝光和最终色调映射放在预览壳。

附固定种子截图、主要设备清单、分组与锚点说明、实际占地和释放方法。在独立预览中检查创建、移除与释放后没有遗留动画或监听即可；不要求运行游戏、整片银河或 30 次游戏导航验收。最终交付可编辑代码与可提取工厂，截图或单个 HTML 演示不能替代模型代码。
