# 内部：建筑覆盖与首都接入映射

本文供游戏接入和美术验收使用，**不发给外部制作方**。建筑名称以 `game/catalog.mjs` 为准；可建造天体以 `game/engine.mjs` 的服务端校验为准。核对日期：2026-10-18。

目录共 **20 个既有建筑 ID**。先前外部任务涉及三类开采综合体、三类仓储和太空电梯，共 7 个 ID；新首都模型覆盖剩余的 10 个普通星球建筑；另有 3 个月球专属建筑，单独作为月球模块。

下文“已覆盖”只表示已纳入之前发出的制作任务，**不表示已收到合格文件或已接入正式游戏**。三类仓储尤其需要验收是否确实提供了可单独提取的子组。

## 首都的视觉分区

“首都”是 10 个现有设施集中呈现的美术组织方式，不是新增的经营建筑。建议以行政与研究核心、制造区、公用工程边缘和物流入口组成一片完整园区；现有矿区和电梯用道路、管线或物流接口与其相接，不重复再造一套。

| 视觉区域 | 通用 key | 对应既有 ID | 布局与功能边界 |
| --- | --- | --- | --- |
| 行政与协作区 | `command`, `allianceLogistics` | `Command_Center`, `Alliance_Depot` | 主基地形成中央识别点，联盟设施邻近对外入口。`allianceLogistics` 是模型名称；目录中联盟设施的真实用途是建立或加入联盟，不据此增加贸易、运输产量或联盟仓储规则。 |
| 科研区 | `research` | `Research_Lab` | 实验室与仪器区有独立院落和连接通道；无需新增学校、研究机构或科技条目。 |
| 制造与施工支持区 | `robotics`, `nanofab` | `Robotics_Facility`, `Nanite_Factory` | 机器人工厂表现大型设备与装配，纳米工厂表现精密封闭加工；仍只承担各自现有建造加速效果，不新增商品生产线。 |
| 能源与地形工程区 | `solar`, `fusion`, `terraforming` | `Solar_Plant`, `Fusion_Reactor`, `Terraformer` | 光伏阵列位于开阔边缘，聚变设施保留检修与安全空间，地形工程设施靠近园区与自然地貌的过渡侧。地形改造器不是防护罩，其规则仍是增加建筑空间。 |
| 监测与行星保障区 | `radar`, `planetarySupport` | `Radar_Facility`, `Missile_Silo` | 雷达设置在视线开阔处，保障中心连接物流入口、维修场与防务仓储。保留现有导弹储位规则，不把整个园区当作新增防御单位。 |

每个 key 应提供独立子组、占地和观察锚点，接入时映射回自己的建筑 ID。不能因为合成同一首都模型就统一等级、施工、升级、库存、能源或停工状态，也不能因为显示了装饰设施就自动授予经营收益。围栏、道路、绿地、普通办公配楼等可作为园区装饰，不创建新的经营 ID。

服务端目前保留普通星球的 14 个固定球面槽位，见 `game/surface-layout.mjs`。首都模型的集中布局属于后续视觉接入：经营操作仍提交对应建筑 ID 和既有合法槽位，不能直接把多个经营 ID 改成一个“首都槽位”。独立外部模型无需理解这些槽位；由我方完成视觉锚点与逻辑建筑的映射。

## 月球单独处理

`moonBase`、`lunarRadar`、`jumpGate` 只用于月球，不放入普通星球首都。月球还可复用 `robotics`、现有电梯，以及从三类资源综合体提取的仓储子组；复用仓储不代表在月球放入矿坑或开启资源开采。

月球不应随普通首都模板带入 `command`、`research`、`solar`、`fusion`、`nanofab`、`radar`、`allianceLogistics`、`terraforming` 或 `planetarySupport`。月球雷达 `The_EU_X_Radar` 与普通雷达站 `Radar_Facility` 是两个不同建筑，不混用 ID。

## 当前映射差异与核对来源

- 服务端 `game/engine.mjs` 的建造白名单不允许月球建造 `Alliance_Depot`；当前 `scripts/universe/planet-surface.js` 的月球显示候选过滤却包含此 ID。这里仅记录差异，未修改代码；后续视觉接入以服务端规则为准，不据显示候选扩展玩法。
- `game/surface-layout.mjs` 中历史视觉 type 将 `Alliance_Depot` 标成 `shipyard`、将 `Terraformer` 标成 `shield`。这些是旧外观分类，不是经济功能定义；本次新模型映射分别使用 `allianceLogistics`、`terraforming`。
- 名称及目录：`game/catalog.mjs`；天体建造限制：`game/engine.mjs` 的 `startBuilding` 和 `build` 操作校验；既有表面槽位：`game/surface-layout.mjs`；当前显示过滤：`scripts/universe/planet-surface.js`。

本次仅整理内部映射，没有新增、删除或合并建筑，没有调整前置条件、月球限制或经济规则，也没有修改正式存档或运行游戏服务。
