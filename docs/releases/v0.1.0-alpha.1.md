# 银河帝国 v0.1.0-alpha.1

首个 Windows 本地单机 Alpha 候选版，准备日期：2026-10-20。

## 可以体验什么

- 从银河、恒星系连续进入行星、月球与本方基地，在同一三维世界中查看设施和舰船。
- 建设殖民地、研究科技、生产舰队和防御设施，使用帝国总览、建设计划与恒星系物流管理多个基地。
- 派遣、运输、侦察和交战；查看战报、回放历史战斗，或接管自己的战斗舰。
- 四类行星、野怪据点、月球行动及高级舰队。
- 独立的 Windows 启动器：启动、保存停服、重启和切换本地账号。

## 本轮规则

- 造舰与防务分别使用独立的 8 批次队列。防务在行星保障中心生产，旧混合队列按现行规则迁移。
- 武器对不同目标采用范围溅射倍率与暴击规则；爆炸范围显示真实半径。
- 单机资源经济、建设计划离线推进和本地自动保存沿用当前实现。

## 安装与更新

使用随包的 `开始游戏.md`。需要 Windows、Node.js 24.x 和支持硬件加速的浏览器。发行包已构建，不需要安装 npm 依赖。

新玩家使用空白存档；老玩家在停止旧后台后备份并迁移完整 `data/`。测试存档和开发者账号不随包提供。

## Alpha 范围

- 当前开放第 1 银河的 499 个恒星系；其他银河不作为本次体验范围。
- 大规模战斗、驾驶舱和近地复杂场景仍可能造成帧率下降，未给出最低硬件配置或跨设备性能保证。
- 死星月球改造、主动开启的星球防守玩法仍属于设计计划，不计入本次已交付功能。
- 资源和数值仍会调整。请保留升级前完整备份。
- 素材再分发权限尚需整理，见 `ASSET-NOTICES.md`；当前候选包未公开发布。

构建、回归结果和发布前剩余事项记录在源码仓库的 `docs/releases/PREPARATION.md`。
