# 银河帝国 0.1 Alpha · 开始游戏

这是 Windows 本地单机预览版。游戏后台在自己的电脑运行，浏览器显示三维星图和管理界面。

## 第一次运行

1. 安装 Node.js 24.x，并确认终端中 `node --version` 能显示版本号。
2. 完整解压发行 ZIP 到一个可写的新文件夹，不要在压缩包里直接运行。
3. 双击 `银河帝国.cmd`，在监控窗口点击“启动后台”，再点击“进入游戏”。
4. 首次进入会创建自己的宇宙和账号。进度保存在解压目录的 `data/`。

发行包已包含构建好的页面、模型和音频，**不需要 Git、Git LFS、npm install 或重新构建**。请使用开启硬件加速的 Chrome 或 Edge；本轮验收使用 Windows、Node.js 24.11.1 和 Chrome。

默认游戏地址为 <http://127.0.0.1:8289/>。不能直接打开 HTML 文件，也不要把后台端口暴露到公网。

## 保存、退出和更新

- 关闭浏览器或监控窗口不会停止后台。退出时，在监控窗口点击“保存并关闭后台”。
- 同一台电脑只运行一个正式版本。启动器会连接已经运行的 8289 后台，所以切换版本前要先保存并停止旧后台。
- 更新前，复制整个旧版文件夹作为恢复副本；至少完整备份 `data/`，包括账号会话、宇宙存档及战斗记录目录。
- 新版解压到新目录，在首次启动前复制旧版完整 `data/` 到新目录，再启动新版。
- 回退时，停止新版，使用旧版程序和更新前备份一起恢复。不要让旧版程序直接读取已经迁移的新存档。

## 遇到问题

启动器日志位于 `output/galactic-command/server.log`。反馈时附版本号、复现步骤、浏览器版本和截图。不要公开上传 `data/`、完整账号信息或未经检查的日志。

Alpha 的功能和数值仍会调整。当前范围和已知问题见 `RELEASE-NOTES.md`；素材来源和待核对的分发条件见 `ASSET-NOTICES.md`。
