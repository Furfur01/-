世界继续使用原有唯一 Three.js canvas。建筑页面直接控制原地表镜头；防御显示设施参考图并定位保障中心。管理页顶部资源栏及底部导航有稳定深色背景。

## 存档隔离

`tests/command-ui-harness.mjs` 每次创建全新测试宇宙、明确命名的测试账号、临时 `EMPIRE_SAVE_FILE` 与 `EMPIRE_SESSION_FILE`，随机端口明确排除 8289 与 8390。独立浏览器会话只连接该测试服务；finally 关闭浏览器和服务，校验临时目录边界后删除。上述记录均有 `temporaryRemoved: true`。

本轮未连接正式服务 8289，也未读取或修改 `data/universe.json`、`data/session.json`。未改动游戏引擎、账号或进度。正式页面文件和构建产物已更新；刷新游戏页面即可加载。

## 当前重建入口

```powershell
npm run build:ui
npm test
```

`build:ui` 只生成管理 UI 的 bundle、CSS 与设施图片。完整 `build:command` 也包含这一步。`npm test` 不再覆盖上方历史浏览器矩阵。
