## 玩家看到的数值分别表示什么

1. **基础值**：未加科技；档案、造舰与靶场概览来自同一目录。
2. **当前科技值**：舰体 / 护盾 / 攻击各按对应科技每级 +10% 基础值计算，不包含指挥光环、手动火力、暴击和命中率。造舰详情可展开对照。
3. **标准 DPS**：科技后攻击 / 6；湮灭之星是一次性爆炸，不计算持续 DPS。深空吞噬者的蜂群与指挥效果另按单机规则结算。
4. **战略航速**：燃烧 / 脉冲 / 超空间引擎分别每级 +10% / +20% / +30%；高级舰使用超空间引擎。后端、现代派遣页与旧版派遣页共用报价函数。混编取最慢舰，燃耗按任务距离与速度档计算。
5. **战场速度**：空间战斗的移动速度，与战略航速分开。溅射、暴击、特殊武器与靶场演练缩放均是本地机制。

新入场舰使用新目录与当时科技。已入场舰的舰体、护盾、攻击和运动配置保存于战斗断点，不追溯重算；旧战报保持原记录，返航和已付费队列不重新扣费。已有舰数、账号及资源无需迁移或重置。

## 尚缺或不再另建的原版链

- **先锋实验室及高级研究**：[Pioneer Lab](https://galaxyempire.fandom.com/wiki/Pioneer_Lab) 是原版条目；本地未实现独立建筑。高级舰解锁已由五项新科技和月球旗舰中心承担，本轮不再叠一套先锋门槛。超高温、反重力、合金探测、动力及联合制导等独立作用继续归 P2 核实。
- **氪晶研究与配装**：归 P1；不成为当前舰船的制造前置。
- **活动材料**：高级舰不恢复限时材料、外星部件或充值要求；常驻材料支线归 P2。
- **死星 / 旧守护者**：未开放制造。引力子保留条目，不宣传为当前造舰必修目标。死星地形方案归 P2。

当前可制造单位的前置引用、循环依赖、等级上限与建筑位置在现有测试中核查；基本舰船和高级舰没有新增网游活动门槛。
