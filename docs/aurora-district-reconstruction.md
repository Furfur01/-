# AURORA 星球与建筑群重构

验收日期：2026-10-18。

## 可视预览

独立只读预览：http://127.0.0.1:8390/opendesign/tools/aurora-districts/

可切换类地星、熔岩星、火星、气态星，14 类建筑群，全球/近景，白昼/黄昏/夜间，以及三档画质。拖动旋转、滚轮缩放。该预览使用内存中的展示数据，不连接游戏账号接口。正式前端产物已重新构建。

## 最终行为

- 14 个建筑位置沿用 AURORA 的球面分布，覆盖整个星球；坐标不因所有权、建筑等级或画质变化而搬迁。
- 每个完整建筑群包含 100 栋主体设施。使用原 AURORA 的厂房、穹顶、雷达、储罐、吊机和能源设备几何，保留白墙、深色屋顶、青色与黄色点缀。组团围绕弯折道路生成，建筑朝向与位置错开。
- 普通建筑与树木明显降低。主体建筑高度约 2–2.88 个模型单位，地面附属设施最高约 3.4 单位，树木约 1.25–2.45 单位；模型单位随星球半径缩放。
- 金属矿生成山体和露天采坑，晶体矿生成矿谷与晶簇；建筑落脚区进行平整并向外围地貌过渡。气态星建筑采用独立浮台、管线与连接桥。
- 航天港保留地面设施、太空电梯、轨道船坞与造舰进度表现；建造进度逐步显示建筑，停工时物流动画暂停。
- 地形改为连续的三角形地质切面，移除细碎高频凹凸和着色噪声；仍保留近景自适应细分和高档画质。陆地、海面、熔岩和气态云层延续四种星球的配色。
- 建筑采用共享几何和实例化绘制，精细建筑群缓存上限为 4，其余建筑群使用远景表示；降低远景和切换场景的资源占用。

## 验证结果

- `npm run test:world`：103/103 通过。记录见 `output/aurora-world-tests.txt`。
- 建筑群审阅：四种星球、14 类近景、昼夜、三档画质；无浏览器错误、WebGL 错误。报告与截图：`output/playwright/aurora-districts/`。
- 正式界面隔离验收：四种星球切换、14 个建筑跳转、真实鼠标拾取、轨道船坞，以及保持同一渲染器。报告：`output/playwright/aurora-districts/formal/verification.json`。
- 算法检查包括：建筑不重叠、道路间距、非棋盘布局、地基贴合、矿区地形、球面接缝、CPU/Worker 一致、建造状态、缓存上限与资源释放。
- 标准档单块地形的三角形由 1,344 降至 640，减少约 52.4%；这是单块网格的节省，不等同于整场景耗时或内存减半。高档网格分辨率保留。
- 游戏测试均使用独立临时端口、临时存档与独立会话；测试服务和临时数据已清理，测试账号未进入正式存档。正式 8289 服务未用于测试。

## 主要实现

- `scripts/universe/aurora-district-layout.js`：球面分布、组团布局与地形约束。
- `scripts/universe/aurora-building-source.js`：保留的 AURORA 建筑几何。
- `scripts/universe/aurora-district-model.js`：实例化建筑、道路、绿化、浮台与轨道设施。
- `scripts/universe/continuous-planets/faceted-field.js`：连续 Lowpoly 地形采样。
- `scripts/universe/continuous-surface.js`：正式星球渲染、远近景缓存与拾取接入。

四张设计参考保存在 `output/imagegen/aurora-building-clusters/`；程序场景对应实时可交互模型，截图作为最终视觉验收记录。
